# Market Analysis — Telegram RPG / bot games

> Дата огляду: 12026-06-12. Це робочий зріз, а не повний аудит усіх ботів.

## Категорії аналогів

### 1. Telegram text MMORPG
Приклади:
- Chat Wars — відомий Telegram MMORPG з ботом, API, ґільдійною/соціяльною метою.
- Ligmar — позиціонується як MMORPG у Telegram без встановлення окремого застосунку.
- IdleRift / RiftWars / Noctis Imperivm / SynthLoom та інші новіші боти з PvE, PvP, crafting, leaderboard, ґільдійними або squad-механіками.

Сильні сторони:
- Довга прогресія.
- Соціяльність і війни/рейди.
- Уже доведена життєздатність формату.

Слабкі місця для нашої ніші:
- Часто англійська або російська мова.
- Тон здебільшого generic fantasy/anime/cyberpunk.
- Новачку складно зрозуміти, «де фан» у перші хвилини.
- Багато проєктів виглядають як механіка без сильного письменницького голосу.

### 2. Dungeon crawler / group RPG bots
Приклади:
- DungeonBot / dungeon crawler bots.
- Open-source RPG Monster Game Bot for Telegram groups.
- Різні dice roller / D&D utility bots.

Сильні сторони:
- Прості правила.
- Добре працюють у групах.
- Менше ризику роздути MMO-системи.

Слабкі місця:
- Часто це utilities або proof-of-concept, не live service.
- Не завжди є economy, seasons, retention loop.
- Менше авторського світу й гумору.

### 3. Telegram Mini Apps / HTML5 games
Telegram підтримує HTML5 games і Mini Apps, які запускаються всередині Telegram. Це дає шлях до майбутнього UI для інвентаря, карти, профілю, магазину косметики.

Сильні сторони:
- Кращий UX для інвентаря та складних екранів.
- Можна робити красиві ілюстрації й анімації.

Слабкі місця:
- Більший frontend scope.
- Може розмити головну фішку «текстова гра в чаті».
- Для MVP краще не починати з Mini App, якщо немає готової frontend-команди.

### 4. Україномовна RPG/НРІ спільнота
Є активні українські НРІ/D&D-спільноти та канали, наприклад ІНРІУМ. Це не прямий конкурент, а потенційний канал тестування, контентних колаборацій і перших гравців.

## Ніша
Найперспективніша ніша: **«україномовна комедійна Telegram RPG для друзів і маленьких спільнот»**.

Не варто позиціонуватись як «найбільша MMORPG у Telegram» на старті. Краще: «гра, яку хочеться закинути в чат, бо там смішні монстри, дивний лут і зрозумілий прогрес».

## Диференціатори
1. Українська мова й локальний гумор.
2. Fun-per-message: кожна дія має дати жарт, несподіванку або емоцію.
3. Group-native дизайн: бот оживляє чат, а не просто живе в приватці.
4. Невисокий поріг входу: «3 кнопки до першої перемоги».
5. Сезонність без токсичного FOMO.
6. Відмова від crypto/P2E як брендова перевага.
7. Контентна фабрика: додавати монстрів/предмети легко через data files.
8. Меми як loot: предмети мають бути скріншотними.

## Ризики
- Роздути MMO до того, як core loop став веселим.
- Зробити «локалізацію українською», а не український оригінальний тон.
- Занадто багато RNG без pity/захисту.
- Надто довгі повідомлення в Telegram.
- PvP, який демотивує новачків.
- Спам у групах: бот має бути частиною чату, не флудером.

## Рекомендована стратегія
1. Спершу зробити приватний PvE loop + комедійний контент.
2. Додати одну групову фічу, яку хочеться показати друзям.
3. Відкрити альфу в 2–3 українських гік/RPG чатах.
4. Виміряти retention і скріншотність.
5. Лише після цього — ґільдії, market, seasons, Mini App.
