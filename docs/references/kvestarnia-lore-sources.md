# Джерела для аналізу

> У цьому файлі — публічні джерела, на яких базувався аналіз патернів. Вони не є частиною runtime-фічі.

## Остромаг

- Офіційна сторінка Остромагу: позиціонування як MMORPG у Telegram, текстова пригода у фольклорному світі, 100% українська, живий світ, багато пригод, битви, дослідження, лут, прогрес, спільнота, події.
- Сторінка Telegram-бота Остромагу: українська RPG прямо в Telegram.
- Каталог AllTelegram: описує Остромаг як українську текстову RPG із квестами, боями, прокачкою, внутрішньоігровим чатом, текстовими командами й кнопками, короткими сесіями.

## Telegram RPG / текстові ігри

- DTF: огляд RPG у Telegram; корисні тези про короткі сесії, текстові квести, соціяльність, ринок/чат, зародки лору, раси й NPC в окремих ботах.

## Codex / lore-патерни великих ігор

- BioWare Blog: codex entries, notes, letters, item descriptions; codex як спосіб давати світ без зупинки основного темпу.
- Failbetter / Fallen London: текстова гра з великим обсягом лору, але сильним акцентом на щільні, характерні речення й конкретну дивність.
- Elder Scrolls lore books: in-game texts як окремі книги/томи про світ, фракції, істот, героїв.
- World of Warcraft story/media pages: лор як архів різних форматів — відео, аудіо, комікси, книги, short stories.
- Hades patch notes / codex references: codex entries для персонажів, ворогів, артефактів, індекс і прогресивне відкриття.

## Telegram Bot API

- InlineKeyboardMarkup / InlineKeyboardButton / CallbackQuery: кнопки поруч із повідомленням, callback_data 1–64 байти, необхідність відповідати на callback query.
