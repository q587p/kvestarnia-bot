# 0.3.13 Bugfix Release — Telegram QA

Automated tests cover the deterministic service, routing, presenter and callback contracts. The checks below remain manual until run against the isolated Telegram bot.

## Preconditions

- Refresh the isolated snapshot with `refresh-local-bot.cmd` only when manual testing begins.
- Use one Bard outside Shynok, two level 3+ characters with the Fighting Corner quest, and quest-capable characters at remort `0` and above the class's free remort ranks.
- Record the character's location before each Bard or quest-fight scenario.

## Compact matrix

| Flow | Action | Expected Telegram response | Expected state / replay result |
| --- | --- | --- | --- |
| Bard outside Shynok | Start a performance, refresh/respond, then finish or decline | Performance cards and callbacks work normally | Stored location never changes before, during or after the flow |
| Bard in Shynok | Complete a performance | Existing Shynok-specific house behavior remains visible where applicable | Location remains Shynok |
| Quick Duel quest | Resolve one Quick Duel, then repeat the acceptance/result callback | Quest progress appears once | The same duel cannot add a second progress record |
| Turn duel quest | Complete a valid turn duel and replay its terminal callback | Existing quest progress remains intact | One progress record only |
| Quest fight origins | Trigger Adventure monster fights from the front and yard; redraw, act, flee, and separately win | Every card stays in the fight; terminal button returns to the origin | Stored world location and durable `originLocationId` stay unchanged |
| Ordinary Niz fight | Start and finish a normal Niz fight | Existing Niz cards and navigation remain unchanged | Origin remains the Niz layer |
| Quest level scaling | Start equivalent quest encounters at low and higher levels | Ordinary cards do not expose hidden formulas | Stored monster level follows the current character level |
| Quest remort pressure | Compare remort `0` with a remort count above the free ranks; retry/redraw the opening and a turn callback | Only the adjusted battle opens with `🧿 Відплата за минулі пригоди: монстр бʼється з поправкою на ремортну памʼять.` | Stored stats remain identical on replay; the line is sent once and does not recur on cards |
| Doppelganger quote | Train with a dynamic name containing `<`, `&` or `>` | The comment is visibly a block quote, with valid italics if retained | Telegram payload uses HTML parse mode, one `<blockquote>`, and escaped dynamic text |
