# 0.3.13 Bugfix Release — Telegram QA

Automated tests cover the deterministic service, routing, presenter and callback contracts. The checks below remain manual until run against the isolated Telegram bot.

## Preconditions

- Refresh the isolated snapshot with `refresh-local-bot.cmd` only when manual testing begins.
- Use one Bard outside Shynok, two level 3+ characters with the Fighting Corner quest, and quest-capable characters at remort `0` and above the class's free remort ranks.
- Record the character's location before each Bard or quest-fight scenario.
