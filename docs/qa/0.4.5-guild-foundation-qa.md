## Runtime setup

Use the isolated local bot and three private test accounts. In checkout `.env`:

```env
NODE_ENV=development
GUILD_FOUNDATION_ENABLED=true
```

Run `refresh-local-bot.cmd`, then `status-local-bot.cmd`. Record the snapshot SHA
and copied runtime flag. Account A needs an eligible founder Character (level 7
before the first remort, or level 3 after a remort) and at least 587 gold; B and C only need current
Characters. `/dev_guild_gold` may prepare A outside production. It must never
register, appear or mutate under `NODE_ENV=production`, even with the flag true.
