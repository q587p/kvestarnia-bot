# 0.4.3 Consumable Manatka Uses QA

Status: automated coverage passed on the candidate tree. Manual Telegram QA on
the final exact head remains pending. This document records the required live
matrix; it is not production rollout evidence.

## Setup

- Isolated non-production bot refreshed with `refresh-local-bot.cmd`; record
  the snapshot SHA from `status-local-bot.cmd`.
- Set `CONSUMABLE_MANATKA_USES_ENABLED=true` and
  `DEV_GRANT_COMMANDS_ENABLED=true`, plus the existing non-secret flags needed
  for the selected Party Boss and GroupCombat entry surfaces.
- Use one account for inventory and ordinary single-/multi-enemy combat, and
  three accounts for party surfaces.
- Grant two of each exact catalog id with
  `/dev_add_item 2 itemId=<exact-id>`. Use `/dev_heal` and
  `/dev_restore_mana` to prepare partial and full resources.
