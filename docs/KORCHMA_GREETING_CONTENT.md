# Korchma Greeting Content

## Ціль

Коли герой заходить у залу корчми, корчмар має не просто сказати «вітаю», а відреагувати на те, хто перед ним. Це перший і найвидиміший спосіб показати: вибір раси, класу, звертання/path і титулу щось змінює.

Важливо: це має бути коротко. Корчма — hub, не катсцена.

## Формат у UI

Рекомендований блок у `presentKorchmaHall()`:

```text
🍺 Зала корчми
<b>Імʼя</b> · <i>Титул</i>

Корчма Квестарні тримає тепло, шум і кілька справ, які краще не залишати без нагляду.

Корчмар: «...персоналізована репліка...»

За столами: ...

Куди йдемо?
```

Або, якщо `npcQuote()` уже використовується:

```ts
npcQuote("Корчмар", selectedGreeting)
```

## Вибір реплік

Перший PR може робити одну репліку на вхід:

- exact combo, якщо є;
- інакше race;
- інакше class;
- інакше pronoun/path;
- інакше fallback.

Варіантів на selector має бути 2–4, щоб гравець міг тим самим героєм побачити інший текст.

Не використовувати `Math.random()` прямо в presenter. Для тестів має бути deterministic seed.

## Fallback

- «Заходьте. Якщо ви квест — сідайте зліва. Якщо проблема — теж зліва.»
- «Корчма рада всім, хто не кусає меблі без попередження.»
- «У нас сьогодні знижка на підозри. Берете одну — друга сама прилипає.»
- «Не стійте в дверях. Двері нервують, коли їх квестять.»

## За звертанням / path

Не показувати path names гравцю. Використовувати лише мʼякі жарти.

### `he` / internal `sun`

- «Ага, прямий запис у сонячній шухляді. Не хвилюйтесь, вона теж трохи крива.»
- «Бачу, ви з тих, кому корчма одразу показує головний стіл. Підозріло, але зручно.»
- «Для вас у журналі лишили рівну лінію. Ніхто не знає, хто її там намалював.»

### `she` / internal `moon`

- «Місячна шухляда сьогодні слухняна. Це або добрий знак, або вона щось планує.»
- «Корчма вас памʼятає наперед. Таке тут буває, особливо біля чайників.»
- «Записав. Якщо журнал почне співати, скажу, що це не ви.»

### `they` / internal `boundary`

- «О, межові документи. Поставлю печатку боком — їм так зручніше.»
- «Ваша анкета сама перейшла через поріг. Я тільки не заважав.»
- «Межа підписала пропуск заднім числом. Це найчесніший наш документ цього тижня.»

## Already-seen / repeat входи

Коли герой заходить у корчму не вперше за день:

- «О, знову ви. Стілець казав, що не готовий, але це його проблема.»
- «Повернулись? Добре. Корчма якраз вдавала, що нічого не сталося.»
- «Ваша справа ще тепла. Це або активність, або вона сиділа біля печі.»
- «Я вже відкрив вашу шухляду. Вона спитала, чи можна не сьогодні.»

## Підказка для /restart

Не навʼязувати, але іноді після already-completed/cooldown:

- «Інша біографія — інші підозри корчмаря. `/restart`, якщо хочеться зіпсувати мені картотеку.»
- «Звісно, можна лишитися собою. Але в архіві є порожня полиця під вашу наступну помилку: `/restart`.»
- «Корчма поважає сталість. Але ще більше вона поважає нові приводи для жартів.»
