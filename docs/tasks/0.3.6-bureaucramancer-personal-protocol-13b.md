# 0.3.6 - Bureaucramancer Personal Protocol 13-B

Status: implemented in PR branch.

## Goal

Ship a narrow `class.bureaucramancer` social raid-prep action for Big Barrel Brother recruiting.

A level 3+ Bureaucramancer can file `Протокол 13-Б: персональні претензії` during a live Big Barrel Brother recruiting session. Joined participants may sign once. When the fight starts, each signer blocks the first eligible personal/single-target boss attack against themselves.

This is not a generic bureaucracy engine, a combat class ability catalog change, Warrior Taunt, or broad party mitigation.

## Shipped Behavior

- Eligible joined level 3+ Bureaucramancers see `📄 Протокол 13-Б` on live Big Barrel Brother recruiting cards.
- Filing costs 5 mana, starts a 93-minute Bureaucramancer cooldown only after committed success, creates at most one protocol per recruiting session, and auto-signs the filer.
- A committed protocol remains owned by the recruiting session if its filer leaves; only final joined, remort-valid signatures are frozen into the raid, and a second protocol cannot replace it.
- Duplicate filing callbacks replay the existing state without a second mana spend, second protocol, or duplicate signature.
- Joined participants can sign the open protocol once for free before raid start.
- Duplicate sign callbacks replay the signed state without changing the signature count.
- Non-joined, stale, expired, terminal, non-Big Barrel, remort-mismatched, active-combat-blocked, ineligible, cooldown, and insufficient-mana paths fail closed with Ukrainian copy.
- Recruiting cards show only compact protocol state and signature count. Signer names are not public.
- Starting the Big Barrel fight freezes the joined signer set into party-boss state.
- Each signer blocks the first eligible personal/single-target Big Barrel retaliation against themselves. The stored boss action id, turn, prevented damage, spent count, and signature count replay from boss state.
- `Бочковий гуркіт`, broad/all-party attacks, unsigned targets, and later personal attacks after a signer protection is spent are not blocked.
- Kharakternyk ward signs remain the broad Big Barrel mitigation. Protocol 13-Б runs only on focused personal retaliation, so the same broad damage event is not reduced twice.

## Persistence

- No Prisma schema migration.
- Recruiting state is stored in `PartyParticipant.snapshotJson`:
  - `bureaucramancerPersonalProtocol13B`
  - `bureaucramancerPersonalProtocol13BSignature`
- The filer cooldown uses `characterCooldown` key `class.bureaucramancer.personal-protocol-13b.cooldown`.
- Started Big Barrel boss state freezes only joined, remort-matching signatures into `PartyBossState.personalProtocol`.

## Achievements

Shipped rewardless achievements:

- `achievement.bureaucramancer.protocol.filed`
- `achievement.bureaucramancer.protocol.signed`
- `achievement.bureaucramancer.protocol.triggered`

They grant no XP, gold, item, title-power, or combat power.

## Manual Telegram QA

Manual QA status: pending. Use `refresh-local-bot.cmd` before manual testing, then verify:

1. Start a Big Barrel Brother recruiting session with a level 3+ Bureaucramancer.
2. Verify only the eligible joined Bureaucramancer sees `📄 Протокол 13-Б`.
3. File protocol with enough mana; verify mana spend, cooldown and filer auto-sign.
4. Try duplicate filing; verify no second mana spend and no duplicate signature.
5. Join from another account and sign once.
6. Try duplicate sign; verify count does not increase twice.
7. Verify recruiting card shows count only, no signer names.
8. Start the raid and force/observe a personal boss attack against a signed participant.
9. Verify the attack is blocked for that signer and trigger copy/stored prevented damage appears.
10. Verify a later personal attack against the same signer is not blocked.
11. Verify a personal attack against an unsigned participant is not blocked.
12. Verify `Бочковий гуркіт` / broad boss action is not blocked by the protocol.
13. Refresh/replay active and terminal cards; verify no retrigger or recalculation.
14. Try stale sign after start and terminal state; verify no mutation.
15. Let the filer leave before raid start; verify the protocol remains count-only, no second filing is accepted, and only joined signatures freeze at start.
16. Check performance logs remain quiet unless slow thresholds are hit.

## Integrated Follow-up

- Persistent two-enemy combat Chronicle rows now evaluate the strongest stored encounter enemy for underdog thresholds. Reward calculation still uses the original encounter enemy, while the public event subject reflects the enemy that made the victory notable.
- Added a FightService regression test covering a level 8 primary enemy and a level 23 backup enemy.
- Solo persistent PvE remort revenge now starts at remort `2` for all sources. Its single-enemy pressure uses a bounded stronger curve (`+2` internal stat levels per pressure rank, plus `3 × rank + ceil(rank / 2)` HP and `ceil(rank / 2)` attack), while two-enemy threat pressure retains its separate three-free-rank curve.
- Balance simulation coverage targets approximately 42–60% high-remort wins with a small Monte Carlo tolerance; the revenge notice uses `🕰️`, distinct from the Kharakternyk `🧿` ward sign and `👁` combat ability.
- Quest archive now shows `Бочка, або Туди і звідти` when the beginner Barrel tutorial is unavailable because the character outleveled it without completing the route.
- Priest self-blessing follow-up: the self-blessing button is hidden while `priestSelfBlessAvailableAt` is active; self-heal and available blessings for other targets remain visible.
