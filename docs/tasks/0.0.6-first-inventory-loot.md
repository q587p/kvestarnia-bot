- **Added:** The main menu now includes `🎒 Манатки`.
- **Added:** Tests cover inventory service states, inventory presenter output, new item content IDs, Prisma schema shape, menu callback parsing, and once-per-date item grant behavior.

- **Changed:** README and design/technical docs now describe the first tiny inventory slice.
