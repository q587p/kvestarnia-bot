# 0.3.0 - Charkokovalnia / Item Upgrades MVP

Status: implemented in this task branch.

## Goal

Add a replay-safe, bounded item-upgrade loop for selected manatky without introducing item-instance identity or a broad market/crafting rewrite.

## Scope

- Use concrete item ids for upgrade variants: `base`, `base.plus-1`, ... `base.plus-5`.
- One successful upgrade moves one owned stack unit to the next concrete item id.
- Keep equipped rows aligned when an equipped stack unit is upgraded.
- Use deterministic cost/chance/pity/donor gates.
- Add Iskrokamin / material reward path only as required by the upgrade loop.
- Add Charkokovalnia Telegram callbacks, keyboards and presenters at `Задвірок корчми`, not as a `Манатки` command/shortcut.
- Surface the Charkokovalnia unlock as a spoiler-light `Стіл зі справами` task and quest marker route while the elf-mage handles the field-kit unlock inside Charkokovalnia.
- Add the elf-mage NPC unlock: level 5+, or level 3+ after remort, then consume one `Польова аптечка` and grant dynamic XP.
- Show `Іскровий підкрут` only to magical specialist classes that can actually use the self-temper path.
- Add dev QA helpers behind production-disabled dev gates.
- Add rewardless achievements for first upgrade success, first failed attempt and first `+5` upgrade.
- Add a rewardless first-Iskrokamin achievement now that Iskrokamin can drop from fights.
- Add `legendary` item rarity support above `epic`, without enabling broad legendary drops.
- Update item detail, inventory, equipment, hero/effective-stat and Mantok presentation.
- Treat `+1..+3` as weak magic and `+4..+5`, set pieces and ability-grant manatky as strong magic; magical equipment bonuses require attunement after equip, with magical specialist classes attuning faster.
- Raise visible rarity floors for plus manatky: `+1..+2` at least uncommon, `+3..+4` at least rare and `+5` at least epic, without downgrading already rarer bases.
- Use the rounded log-spaced Iskrokamin cost ladder `2 / 5 / 13 / 34 / 89`, with bounded rarity/set modifiers and percentage donor discounts.

## Non-goals

- No item-instance rewrite.
- No new Prisma migration unless a specific implementation proves unavoidable.
- No market, auction, player-to-player upgrade service or paid power.
- No broad loot/economy rebalance.
- No new combat actions.
- No tournaments.
- No broad plus-drop economy: generated Loot Expansion `-plus-N` rows may drop only as a very rare tail of existing generated loot and do not double-upgrade already generated ids.

## Acceptance criteria

- Preview does not spend resources.
- Stale direct attempts reject before spend when stack/level/pity snapshot changed.
- Concurrent duplicate attempt callbacks from the same preview snapshot claim once and cannot spend or upgrade a second stack unit.
- Successful upgrade mutates exactly one stack unit and replays safely.
- Equipped item alignment remains correct.
- Failed attempts apply pity/cost exactly once.
- Pity and donor bonuses are bounded and visible only qualitatively before commit; exact committed details may appear after an attempt.
- Plus drops remain very rare when generated Loot Expansion candidates are eligible.
- Plus variants display their raised rarity floor and correct weak/strong magic text on item cards.
- Positive post-fight bandage slots can rarely become Iskrokamin instead, never both from the same slot.
- Iskrokamin is transferable through Safe Gifting and postal delivery.
- Existing Mantok set bonuses and Mantok ability grants preserve base-item semantics for upgraded concrete ids.
- Charkokovalnia previews identify set pieces, upgraded set-piece ids resolve to the same base Mantok set, and donor ordering is same-template, then same-set, then same-slot when levels match.
- Equipping magical manatky asks for confirmation, starts `Налаштування на...`, withholds stats/set/ability bonuses until the timer is ready, and warns before replacing a still-tuning slot.
- Replaying equip for the same item already tuning in the same slot is a no-op that preserves the active attunement row.
- `Стіл зі справами` shows `Доступ до Чароковальні` while the unlock is pending; `Задвірок корчми` keeps the Charkokovalnia action highlighted and does not show the daily `До обходу` shortcut.
- If the Charkokovalnia unlock is pending, the player has no field kit, and field-kit crafting is still locked, `Єгерський куток` shows `🧰 Аптечка?`; the hint explains that both Yeger board stages open the route. If the field kit is already owned but Charkokovalnia is still locked, the same hint points back to the Korchma yard.
- Successful upgrades are recorded in `📜 Хроніки Квестарні` under `Манатки`; `+5` successes are marked important.

## Implementation notes

- Upgrade variants for authored eligible equipment manatky are generated in content as `base.plus-1` through `base.plus-5`; authored and generated plus variants share the same visible rarity floors and weak/strong magic labels.
- Upgrade attempts use existing `CharacterItem`, `CharacterEquipment` and `DailyAction` rows; no Prisma migration was required. A one-shot `DailyAction` claim guards each exact stack/pity preview snapshot before resources are spent.
- Charkokovalnia unlock state uses a persistent `DailyAction` key, consumes one field kit and grants bounded dynamic XP.
- The Yeger `🧰 Аптечка?` hint is read-only: it checks the pending Charkokovalnia unlock, shows immediately from every Yeger-corner entry route, points field-kit owners back to the yard, and uses the existing `kit` craft preview to hide itself once second-board or remort-level crafting access exists.
- Pity is stored under a persistent `DailyAction` key per item id and target level.
- `Іскрокамінь` is the only new material item, added only as a Charkokovalnia cost stack.
- Fight rewards can now very rarely replace a positive ordinary-bandage reward slot with bounded Iskrokamin, using compressed quantity mapping.
- Iskrokamin is not trade-blocked; gift and postal eligibility are intentionally consistent.
- Item rarity schema and presenters accept `legendary` (`легендарна`), sort it above `epic`, and keep loot-table legendary weight disabled unless explicitly authored later.
- Quest markers for the pending Charkokovalnia unlock propagate through the Korchma entrance, hall, quest table and yard routes. The table button sends players to the yard; the yard itself no longer duplicates the daily Korchmar round shortcut.
- `/dev_add_iskrokamin [amount]` is available only when the existing non-production dev-grant gate is enabled.
- Weak magic (`+1..+3`) keeps the old small stat scaling and uses a 13-minute equipment attunement, or 5 minutes for magical specialist classes. Strong magic (`+4..+5`, set pieces and ability-grant manatky) uses stronger upgrade bonuses, higher Iskrokamin costs and a 42-minute equipment attunement, or 23 minutes for magical specialist classes. Visible rarity floors follow plus level: `+1..+2` at least uncommon, `+3..+4` at least rare and `+5` at least epic, while `legendary` bases stay legendary.
- Iskrokamin costs are based on the rounded log-spaced ladder `+1: 2`, `+2: 5`, `+3: 13`, `+4: 34`, `+5: 89`; set pieces round up at `x1.25`, legendary items at `x1.5`, and legendary set pieces at `x2.0`. Same-template donors discount `20%`, same-set donors `13%`, same-slot donors `7%`, and the final Iskrokamin price cannot fall below half of the modified cost.
- Pending attunement is stored in existing `DailyAction` rows under the equipment attunement key. Tuning equipment stays visually equipped but is excluded from effective stats, set bonuses and Mantok ability grants until ready; direct unequip, replacement and cross-slot clears cancel the tuning row. The runtime scheduler sends the completion notice, pages past old cancelled/notified rows and marks due rows notified.
- `/dev_finish_attunements` is available only behind the same non-production dev-grant gate and moves pending attunement timers to ready for local QA.
- Lore decision: `📖 Перекази` was reviewed and the manatky entry now fixes the Charkokovalnia NPC as an elf-mage in the backyard, with careful Charkokovalnia strengthening and no promise of markets, crafting or hidden procs.
