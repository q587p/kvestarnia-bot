# 0.2.29 - Mantok Ability Grants Foundation

## Goal

Add a narrow data-driven foundation for rare Mantok equipment that grants visible combat actions or tightly capped service markers in the current level `9..13` band.

## Scope

- Data-driven Mantok ability-grant registry.
- First authored epic/soulbound grant manatky, reusing existing Mantok set pieces where possible and adding one new rapier.
- Gear-action buttons with stable compact callbacks for persistent PvE, Big Barrel Brother/party-boss rounds and turn-based duels.
- Deterministic mana/cooldown gates, active-turn equipment sync and stale callback no-ops.
- One visible bleed/status family.
- Weaker borrowed class/race-style gear actions with `equipment` source.
- Additive high-level monster loot merge.
- Item/equipment presentation for granted actions and perks.
- Remort item selection keeps long eligible manatka lists reachable through pagination.

## Non-goals

- No Shynok, Kosti/table-games, shops, markets, crafting, Prisma schema, item instances or broad combat formula changes.
- No hidden procs, free extra turns, generated ability loot or ability-granting set bonuses.
- Borrowed gear actions do not count as native class/race actions.
- Quick duels stay instant and do not expose gear actions.
- The Yeger cloak ordinary-bandage service perk is documented as a narrow marker only; no dense bandage, field kit, Yeger board or service runtime unlock ships here.

## Acceptance criteria

- Grant keys are stable, deterministic, compact and collision-free.
- Combat start seeds eligible grant ids from the equipped item snapshot.
- Active fight cards and current-turn callbacks refresh eligible grant ids from the current equipped item snapshot, so changing gear during the active turn can add or remove gear buttons without refilling HP/mana or granting an extra turn.
- Gear callbacks reject stale turns, currently unavailable keys and forged blocked mana/cooldown attempts without advancing combat, visible gear callbacks bypass the generic active-combat redirect in persistent PvE, Big Barrel Brother raids and turn-based duels, and active keyboards hide gear-action buttons until their mana/cooldown gates are currently available.
- Bleed is visible, capped, refresh-only and can finish single- or multi-enemy persistent combat without an extra monster response when the status itself lands the terminal damage.
- Gear-action damage/support effects are visible on active cards and stored journals/replays for ordinary fights, Big Barrel Brother raids and turn-based duels.
- Monster loot additions preserve existing base/trophy/coverage/set loot.
- Item detail and equipment cards show granted action/perk summaries.
