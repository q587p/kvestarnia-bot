# 0.2.x - Manatka Equipment Rework and Balance Pass

Draft `0.2.x` task. Start only after the Phase 2 MVP closeout is merged and the first `0.2.x` task order is confirmed.

## Goal

Rework manatky from a small passive equipment shell into a clearer equipment system with multiple meaningful slots, safer item identities and a global balance pass so rarity, price and effects make sense together.

This is not only a one-use/consumable-item task. Consumables can be part of the item-tag roadmap, but the larger problem is equipment structure and item-value balance.

## Scope

- Define the canonical equipment slot model for manatky.
- Support multiple body/gear slots beyond the current tiny shell, for example:
  - main hand;
  - off hand / second hand;
  - head;
  - body / chest;
  - legs / pants;
  - accessory / trinket;
  - optional future special slot if it has a clear gameplay role.
- Decide how two-handed, offhand, paired and accessory-like items conflict.
- Rework inventory/equipment UI so players can compare current item, candidate item and slot conflict clearly.
- Add item tags needed for slot eligibility, trade/gift safety, future consumables and future combat action catalogs.
- Audit all existing reachable manatky for value, rarity, slot, effect and player-facing description.
- Run a global item/equipment rebalance so expensive/rare `+1` or `+2` items are not weaker than cheaper/common alternatives without a deliberate non-combat reason.
- Preserve story, priceless, sentimental and protected item safety.
- Keep combat/domain calculations deterministic and covered by tests.

## Non-goals

- No market, auction, buyback or item-for-item trading in this task.
- No broad quest, loot or reward-table rewrite unless needed to keep item balance coherent.
- No hidden automatic procs without visible preview/confirmation rules.
- No pay-to-win item power.
- No one-off migration that loses existing player equipment.
- No unlimited equipment slots or free stacking of every bonus.

## Acceptance criteria

- Slot definitions are documented and enforced by content validation.
- Equipment persistence supports the chosen slot model and replacement rules.
- Existing equipped items migrate or map safely to the new slots.
- `/equipment`, item detail, `/inventory` and `/hero` show slot, effect and replacement consequences clearly.
- Two-handed/offhand/accessory conflicts are deterministic and tested.
- Item value, rarity and effect strength pass a balance audit with explicit rationale for exceptions.
- No priced common item is strictly better than a more expensive/rarer item in the same practical role unless the exception is documented.
- Consumable/one-use tags, if added, require explicit confirmation and replay-safe consumption.
- Shynok sale, Mantok Chest, Munchkin barter, gifting/trading and remort protection rules still respect equipped/protected/story/sentimental items.
- Existing no-equipment and old-equipment characters remain readable.

## Focused tests

- Content validation for supported slots, tags, rarity/value/effect consistency and invalid conflicts.
- Repository migration/integration tests for multi-slot equipment and replacement.
- Service tests for equip/unequip, two-handed/offhand conflicts, duplicate callbacks and stale inventory.
- Presenter tests for slot labels, comparison copy and Ukrainian player-facing text.
- Effective-stat tests for stacked equipment contributions and caps.
- Regression tests for Shynok sale, Mantok Chest, Munchkin barter, remort and future gifting reservations.
- Balance audit test or report for existing item value/effect outliers.
- Full `npm run check` and combat simulation where item effects can affect combat.

## Manual Telegram QA

1. Open `/inventory`, item detail, `/equipment` and `/hero` for a character with old and new items.
2. Equip main-hand, offhand, head, body, pants and accessory items.
3. Try a two-handed item and verify offhand conflict copy.
4. Replace an equipped item and verify the old item stays in the bag.
5. Try selling/recycling/bartering/gifting equipped and protected items.
6. Verify common cheap items no longer obviously beat expensive rare items in the same role.
7. Verify remort preview and preservation still explain which items move forward.
8. Run a few fights before/after equipment changes and verify visible stats match combat behavior.
