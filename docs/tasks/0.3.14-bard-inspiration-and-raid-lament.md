## Outcome

Ship two bounded Bard support mechanics:

- a normal performance grants free, non-stacking `✨ Натхнення` to its frozen starting audience for 13 hybrid minutes, worth `+1/+2/+3/+5` percentage points to canonical player hit rolls according to the existing performance grade;
- an eligible Bard in Big Barrel may spend one raid action on `🎻 Заграти журливу баладу`, reducing direct Big Brother retaliation damage by `1/2/3/5` for 8–13 boss responses, once per raid session and only when the encounter’s Barrel music slot is free.

Preserve the current performance economy and social reactions. Tips do not affect combat power.

## Required behavior

### A. Inspiration grant

- Grant inside the performance transaction to the repository’s canonical initial audience.
- Exclude the performer, later arrivals, other locations, active combatants, and current raid participants exactly as the existing audience snapshot does.
- Grant before and independently of applause/tip/decline.
- Reuse the existing performance roll and grade; map `rough/pleasant/memorable/legendary` to `+1/+2/+3/+5` accuracy percentage points.
- Store source performance, Bard, normalized location, recipient life identity, grade, frozen bonus, activation/expiry/cursor data, and rules version.
- Strictly stronger Inspiration replaces and resets to 13 minutes. Equal or weaker Inspiration neither replaces nor refreshes.
- Recipient remort invalidates the state. Source remort/movement/class change does not revoke an already granted state.
- Do not add a Prisma model or migration; use the established versioned `CharacterCooldown` payload pattern unless a proven blocker requires stopping for review.

### B. Accuracy application and hybrid duration

- Add `accuracyBonusPp / 100` before the canonical player hit-chance clamp for basic and roll-based offensive actions.
- Do not affect damage, crit, healing, flee, guard, items, passive/scripted damage, or effects without a hit roll.
- Apply actor-locally in PvP and per participant in raid; never mutate permanent/frozen character stats globally.
- Mirror `Ситий` for durable combat modes: freeze outside duration on lease acquisition, pause wall time, apply the bonus to the current action, pulse one minute after each committed player turn, and release the exact remainder.
- Support persistent single/multi PvE, training, turn-based duel, and Big Barrel through the same shared lifecycle. Keep quick duel unchanged if it has no canonical persistent pulse.
- Duplicate, stale, rejected, replayed, or no-op callbacks never pulse.
- Generalize the single `ActiveCombatLease` release/synchronization path so `Ситий` and Inspiration are handled atomically. Do not let two status-specific release calls race to delete the lease.

### C. Raid music slot and Lament action

- Initialize versioned encounter-local Bard music state when the recruiting party becomes an active boss session.
- Mark the slot `inspiration` only when a starting participant has valid Inspiration sourced from the normalized Big Barrel presence location.
- Compare against `PRESENCE_LOCATION_KORCHMA_BARREL` (`location.korchma.barrel`), not the different party-origin marker `BIG_BARREL_PARTY_ORIGIN_LOCATION_ID` (`barrel.big-brother`).
- Do not let unrelated/expired performances or performances from other locations block the raid.
- Treat the active-boss participant snapshot as fixed for this slice. If the post-0.3.13 code unexpectedly permits joining an already active boss, stop and report the product conflict rather than inventing suppression/timer behavior.
- Offer `🎻 Заграти журливу баладу` to a living joined Bard in an active raid with a free music slot and ready shared local availability. Do not require maximum party size.
- The successful callback atomically claims the slot, locks/replaces the Bard’s action for that round, freezes the quality result, and begins the shared 93-minute per-Bard/per-Barrel availability.
- The action deals no damage, grants no Inspiration, costs no mana/gold/item, and creates no payout/tip flow.
- Two concurrent Bards: exactly one succeeds. The loser keeps the ability to choose another action and spends no turn/cooldown/resource.
- Duplicate/stale/inactive callbacks are idempotent and show the current reason/remaining wait.
- A committed Lament cannot be replaced with another action in the same round.

### D. Lament balance and damage order

- Reuse the existing performance grade calculation with deterministic activation RNG and frozen Bard stats.
- Map grades to direct boss damage reduction `1/2/3/5`.
- Set duration to `clamp(frozenBardLevel, 8, 13)` actual Big Brother responses.
- The activation round response is first. Decrement after the whole response, once per boss response, not per target.
- Apply `max(0, damageBeforeLament - N)` to each actual target after current base/focus/broad/armor/guard/action reduction and before Kharakternyk Ward and Bureaucramancer Protocol. This is an explicit Lament exception to the normal landed-hit minimum; do not re-inflate zero to one.
- A broad response benefits each actual target but spends one counter. A Taunt-redirected broad response is one redirected damage instance.
- Do not reduce environmental, percentage, settlement, self, or scripted damage outside direct Big Brother retaliation.
- Persist the effect and remaining counter in raid JSON. Source death/exit/remort/class change does not cancel a committed song. Raid completion/cancel clears it; it never transfers.

### E. Shared local availability

- Add one canonical per-character/per-location Bard music availability key with current persistence primitives.
- Successful normal performances and successful Laments write the same 93-minute local availability.
- Normal performance checks honor both historical performance rows and the new key; Lament checks both as well.
- All blockers show the canonical remaining wait from `availableAt` and current `now`.
- Commit the cooldown atomically with the corresponding performance or Lament state. Do not ship a best-effort two-write flow.

### F. Player-facing surfaces

- Show Inspiration grant/replacement/no-change in audience notifications without tying it to payment.
- Show only tip amounts affordable from the audience member's frozen notification balance; keep the transactional balance check authoritative for stale callbacks.
- While the current Bard's same-life performance is still live at the normalized current location, `/online`, Shynok, and the bar must show one personal line with the remaining reaction window and must not offer another `🎶 Виступити` button. Other Bards and other locations keep their own independent eligibility.
- Show exact current strength and canonical remaining duration on relevant status/combat surfaces.
- Present active timed buffs through one shared Telegram formatter. A single Inspiration uses `✨ Стан: <b>Натхнення</b> ще <b>13 хв</b> — <b>+1</b> до влучання.`; when `/hero` has several active timed states, group them under `<b>Стани:</b>` and omit repeated `Стан:`/`Баф:` labels from the individual rows.
- Add the Lament button, success/failure alerts, active raid line, round journal activation/effect/expiry, and restart-safe stored result text. Fold the activation reduction into the Bard action after a colon instead of repeating the song as a second action line. The active battle card shows Lament once above the action history; journal pages place the round's active Lament, Inspiration, `Ситий`, and every other stored buff/debuff/cooldown snapshot under `<b>Кулдауни та ефекти:</b>`.
- On Big Barrel recruiting cards with a Bard, explain that Lament becomes a combat action after raid start when the music slot is free, including for a one-member raid.
- Keep same-period legacy solo Barrel pending state mutually exclusive with Big Barrel creation/join/start. Treat a due-but-unclaimed legacy row as pending, revalidate at the atomic boss transition, and let the leader's start button recover an elapsed Big Barrel recruiting deadline through the same allowance as the scheduler.
- Keep Telegram messages compact and all player-facing text Ukrainian.
- Use distinct icons for normal performance, Inspiration, and Lament on adjacent surfaces.
- Restore the Tavern raid-prep daily tip:

  > Барди у повному рейді дають бафи, дебафи й відповідають за моральний стан табуретів.

- Keep the more specific support explanation on the Big Barrel-specific surface:

  > Перед рейдом Бард може надихнути товариство виступом, а в самому рейді — послабити Старшого Брата журливою баладою. За моральний стан табуретів він усе одно відповідає.

- Review existing Bard performance achievements for regressions; the Lament must not increment completed-performance counters unless it deliberately creates a canonical performance record (not recommended).
- Recipient remort resets Inspiration; raid state follows existing raid-remort settlement behavior; shared local availability follows the same life-bound policy as current performance cooldown unless current code proves it is character-history state. Cover the chosen contract in tests and PR body.
- Update `docs/design/raid-role-flavor-notes.md`, the stale future-only source comment, and relevant Lore Board/reference text if it contradicts the shipped mechanic. If no Lore Board change is necessary, state why in the task/PR.

Implementation decision: no achievement was added because Inspiration extends the existing performance action and a first-Lament reward could pressure a tactically inferior action. Inspiration and shared music availability are character-life state and are removed by the existing remort cooldown cleanup; Lament is encounter JSON and ends with that raid. `📖 Перекази` now describes the shipped Bard combat action, Shynok performance and voluntary tips, payment-independent Inspiration, and Big Barrel Lament. No schema or migration was needed.

## Acceptance criteria

1. Current performance payouts/reactions/location behavior remain correct and combat power never depends on tips.
2. Each eligible initial listener gets exactly one correct Inspiration mutation atomically with performance start.
3. `+1/+2/+3/+5` modifies only canonical player hit rolls and never damage/crit.
4. Thirteen-minute hybrid timing is replay-safe and consistent with `Ситий` across all shipped durable combat modes.
5. One lease release safely synchronizes both timed statuses without extending, losing, or double-pulsing either.
6. Barrel-origin Inspiration and Lament cannot both occupy one raid session’s music slot.
7. A successful Lament consumes the Bard’s action and shared local availability; failed attempts consume neither.
8. Lament reduces exactly the intended direct boss damage in the established mitigation order for exactly 8–13 actual boss responses.
9. All new state survives restart and respects remort/session cleanup; no effect carries into a new raid.
10. Runtime/presenter/callback tests cover idempotency and concurrency; the existing performance and raid suites stay green.
11. Release/docs/player copy are current, Ukrainian, correctly dated, and honest about availability/manual QA.
12. The implementation is committed, pushed, and opened as a draft PR to `main`; it is not merged or deployed by this task.
