# 0.3.x - Bureaucramancer Personal Protocol 13-B

## Goal

Ship a narrow `class.bureaucramancer` social raid-prep action for Big Barrel Brother:

> A level 3+ Bureaucramancer can open `Протокол 13-Б: персональні претензії` during live Big Barrel Brother recruiting. Joined participants may sign once. In the resulting fight, each signer blocks the first personal/single-target boss attack against themselves.

This is not a combat class ability change and does not rebalance `src/content/playerAbilities.ts`.

## Scope

- Add a narrow Bureaucramancer personal-protocol feature, not a universal bureaucracy engine.
- Surface the action on live Big Barrel Brother recruiting cards for eligible joined Bureaucramancers.
- Filing requirements:
  - `class.bureaucramancer`;
  - level 3+;
  - joined participant in a live Big Barrel Brother recruiting session;
  - no blocking active flow;
  - enough mana;
  - no current actor cooldown.
- Filing cost: `5` mana.
- Filing cooldown: `93` minutes per Bureaucramancer after successful filing.
- One personal protocol per Big Barrel recruiting session.
- Successful filing auto-signs the Bureaucramancer if they are joined.
- Joined participants may sign once before raid start.
- Signing is free: no mana, gold or item spend.
- Recruiting cards show signature count only; no public signer list.
- Starting the Big Barrel fight carries the signer set into party-boss runtime.
- For each signer, the first eligible personal/single-target boss attack against that signer is blocked for that signer:
  - immediate damage from that one boss action to that signer becomes `0`;
  - store the prevented damage and boss action/turn id;
  - mark only that signer's protocol signature as spent;
  - other signers keep their own unspent protection.
- Do not block broad / area / all-party attacks such as `Бочковий гуркіт`.
- Add Ukrainian player-facing copy for filing, signing, blockers and trigger/journal lines.
- Update Lore Board class entry after runtime behavior ships.
- Update release surfaces.

## Non-goals

- No new class or race.
- No new location in this MVP.
- No shared broad/special attack mitigation; that belongs to Kharakternyk ward signs.
- No quest/adventure appeal system.
- No office/permit/queue framework.
- No item crafting, paper consumables, shops, markets, bribes or paid advantage.
- No public signer names.
- No XP, gold, item, hunt, quest or achievement power rewards from filing/signing.
- No exact hidden formulas in pre-commit player-facing copy.
- No native combat class ability changes.
- No quick duel behavior.

## Acceptance criteria

- Eligible level 3+ joined Bureaucramancers see a `Протокол 13-Б` action on live Big Barrel Brother recruiting cards.
- Ineligible actors do not see the action; direct/stale callbacks fail closed with clear Ukrainian copy.
- Successful filing spends exactly `5` mana, starts the `93` minute actor cooldown, creates at most one protocol for the session and auto-signs the filer.
- Duplicate filing callbacks do not spend mana twice, create a second protocol or add duplicate signatures.
- Joined participants can sign once before raid start.
- Signing does not spend resources and does not reveal signer names publicly.
- Duplicate sign callbacks replay/confirm the signed state without changing the count twice.
- Non-joined, remort-mismatched, stale, already-started or terminal-session sign callbacks do not mutate.
- Recruiting cards show protocol state and signature count only.
- Starting the Big Barrel fight carries protocol signer state into party-boss runtime.
- The first eligible personal/single-target boss attack against each signer is blocked for that signer and spends that signer's protocol protection.
- Later personal attacks against the same signer are not blocked by the same protocol.
- Personal attacks against unsigned participants are not blocked.
- Broad/special/all-party attacks are not blocked by this protocol.
- Trigger result is stored and replayed in active summaries/journals without recalculating or retriggering.
- If Kharakternyk ward signs or another one-shot raid-prep mitigation already exist in the target branch, document the scope split and ensure the same damage event is not reduced twice.
- Lore Board Bureaucramancer entry mentions the new personal-protocol behavior without implying a generic paperwork engine.

## Manual Telegram QA

Manual QA status: not run in this planning package.

Checklist:

1. Create a Big Barrel Brother recruiting session with a level 3+ Bureaucramancer.
2. Verify the protocol action appears only for the eligible Bureaucramancer.
3. File protocol with enough mana; verify mana spend, cooldown and filer auto-sign.
4. Try duplicate filing; verify no second mana spend and no duplicate signature.
5. Join from another account and sign once.
6. Try duplicate sign; verify count does not increase twice.
7. Verify recruiting card shows count only, no signer names.
8. Start the raid and force/observe a personal boss attack against a signed participant.
9. Verify the attack is blocked for that signer and that trigger copy/stored prevented damage appears.
10. Verify a later personal attack against the same signer is not blocked by the same protocol.
11. Verify a personal attack against an unsigned participant is not blocked.
12. Verify a broad/special/all-party boss attack is not blocked by the protocol.
13. Refresh/replay active and terminal cards; verify no retrigger or recalculation.
14. Try stale sign after start and terminal state; verify no mutation.
