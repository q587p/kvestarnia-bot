# 0.2.x - Consumable Manatka Uses

Status: draft follow-up, not active. Do not implement this inside `0.2.31`.

## Goal

Give non-medical consumable manatky real, replay-safe uses and make useful consumables discoverable from the existing one-use / `Разові` surfaces.

## Context

Some generated consumables currently render truthful non-equipment copy but have no practical action, for example:

- `Кава «Ще Один Квест»`
- `Чай «Заспокойся, Танку»`

They should not feel like equipment and should not become hidden procs. If they are tagged as consumable/one-use and have an actual supported effect, they should be reachable from the same one-use inventory affordances as other consumables.

## Scope

- Audit generated and authored consumable manatky that currently have no use.
- Define a compact use catalog per item family or concrete item id.
- Scale effects by rarity, `goldValue`, level band, tags and existing balance pressure.
- Make supported useful consumables appear in the existing `Разові` / one-use inventory surfaces.
- Keep item-detail copy truthful: consumables are applied, not equipped.
- Consume exactly one stack unit only after the action commits.
- Add stale/replay protection for preview, confirm and callback flows.
- Add focused tests for inventory visibility, item detail, consumption, stale callbacks and balance caps.

## Design guardrails

- Prefer short-lived, bounded effects or immediate utility over permanent power.
- Avoid exact future reward promises before commit.
- Do not create a shop, market, crafting rewrite, item-instance migration or broad economy loop.
- Do not make consumables mandatory for ordinary progress.
- Do not let rarity or price create runaway combat power.
- Consider separate behavior for combat-safe, out-of-combat and social/flavor consumables.

## Candidate effect directions

- Common low-value drinks: tiny HP/mana recovery, minor short-lived comfort effect, or flavorful no-combat utility.
- Uncommon drinks such as coffee: small action-economy-adjacent utility only if bounded and non-repeatable enough to avoid farming loops.
- Rare/epic consumables: stronger but narrow one-shot effects with cooldown, once-per-fight, once-per-period or current-life gates as needed.
- Joke consumables: explicit harmless use result if they should remain flavor rather than power.

## Non-goals

- No implementation in `0.2.31`.
- No new Mantok ability family.
- No hidden proc system.
- No new reward faucet.
- No player market, shop, crafting expansion or Prisma schema work unless the activated task proves a tiny schema addition is unavoidable.

## Focused tests when activated

- Inventory / `Разові` filter includes useful consumables and excludes unusable junk/flavor-only stacks.
- Item-detail use buttons appear only when the consumable has a supported use.
- Confirm/replay consumes one unit exactly once.
- Stale callbacks after quantity, reservation, combat state or remort-life changes do not consume.
- Combat-use consumables do not bypass active-combat turn safety.
- Balance tests cover rarity/value scaling and cap outliers such as generated high-value consumables.

## Manual Telegram QA when activated

- Open `🎒 Манатки` -> `Разові` with coffee/tea-like consumables in inventory.
- Verify useful consumables are visible there and unusable flavor-only consumables are not presented as usable.
- Open item detail and verify short truthful copy plus the correct use button or no-use explanation.
- Use one item, replay the old callback, and verify quantity/effect changes exactly once.
- Try use during active combat, raid and non-combat scenes according to the supported effect type.
