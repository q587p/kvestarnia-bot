# 0.2.x - Dense Bandage And Field Kit

Draft future implementation task. Do not treat this as active runtime scope until a human explicitly starts this version task.

## Goal

Add two craftable medical items made from the existing ordinary bandage:

- `Щільний бинт`
- `Польова аптечка`

Crafting starts from the ordinary bandage item detail card, works only outside combat, and must reuse the current item, inventory, callback and combat-state architecture.

## Scope

- Inspect the current ordinary bandage implementation first: item definitions, inventory stack mutation, item-use previews, combat item routes, cooldown/limit patterns, callback data and item-card refresh behavior.
- Add recipe-shaped configuration for the two new crafts so future extra components can be added without scattered hardcoded checks.
- Preserve the existing ordinary bandage effect; only add craft affordances to its item card.
- Show craft buttons on the ordinary bandage card only outside combat and only when the character has enough ordinary bandages:
  - `Використати`
  - `Створити щільний бинт` when `count(bandage) >= 8`
  - `Створити польову аптечку` when `count(bandage) >= 13`
- Recheck inventory count, combat state, stale callback ownership and duplicate clicks on the backend.
- On successful craft, atomically subtract ordinary bandages, add the crafted item, answer the callback and refresh the item card or inventory state.

## Item Rules

`Щільний бинт`:

- Craft cost: `8` ordinary bandages -> `1` dense bandage.
- Use effect: restore exactly up to `42 HP`, capped by max HP.
- Full-HP no-op: do not consume the item, do not set cooldown, show a normal message such as `HP вже повне.`
- Combat rule: after a successful use, this item has a `5` own-turn cooldown for that character in that specific battle.
- The cooldown must not be global and must reset when the battle ends.

`Польова аптечка`:

- Craft cost: `13` ordinary bandages -> `1` field kit.
- Use effect: raise current HP to at least `ceil(maxHp * 93 / 100)`.
- Use integer arithmetic for the target threshold. Examples: `50 -> 47`, `100 -> 93`, `200 -> 186`.
- No-op at or above the target HP: do not consume the item and do not spend the one-per-fight limit.
- Combat rule: a successful use is allowed `1` time per battle for that character.
- The limit must not be global and must reset when the battle ends.

## Non-goals

- No broad crafting system, shops, trading, economy rebalance or item-instance inventory redesign.
- No rare extra components in the first slice.
- No XP, gold, achievement, title, unlock or hidden reward for crafting or using these items.
- No changes to the existing ordinary bandage heal amount or Єгер bandage supply rules.
- No combat, raid, party or remort rewrite beyond the narrow item-use state needed for these items.
- No Prisma schema or migration unless the current durable combat-item architecture truly requires it; if it does, justify the narrow persistence need in the implementation PR.

## Acceptance Criteria

- Ordinary bandage item cards show craft buttons only when the character is outside combat and has the required ordinary bandage count.
- Exact-count craft works for `8` and `13` ordinary bandages.
- Insufficient-count, stale, duplicate and in-combat craft callbacks fail safely without negative stacks or free items.
- Crafted item use is replay-safe and does not consume on no-op.
- Dense bandage healing is capped at max HP and sets its combat cooldown only after successful healing.
- Field kit target HP uses `ceil(maxHp * 93 / 100)` and spends its combat limit only after successful healing.
- Dense bandage cooldown and field kit one-per-fight limit are scoped to the current character and battle, and do not leak between battles.
- Existing `/news`, board keyboard, item detail and ordinary bandage regression coverage remains green.

## Focused Tests

- Craft dense bandage from exactly `8` ordinary bandages.
- Craft field kit from exactly `13` ordinary bandages.
- Show both craft options when the character has `13+` ordinary bandages.
- Block craft below the required count.
- Block craft during an active fight.
- Prevent double-click and stale callback duplicate crafts.
- Dense bandage heals by `42` or the remaining missing HP, whichever is smaller.
- Dense bandage full-HP no-op does not consume and does not set cooldown.
- Dense bandage combat cooldown lasts `5` own turns and is per battle.
- Field kit uses `ceil(maxHp * 93 / 100)` for `50 -> 47`, `100 -> 93`, `200 -> 186`.
- Field kit no-op above target HP does not consume and does not spend the per-fight limit.
- Field kit can heal successfully only once per battle.
- Combat cooldowns/limits do not leak between different fights or characters.
