# 0.2.28 - Mantok Set Synergies Foundation

## Goal

Add a generic, data-driven equipment set foundation for Mantok items: paired weapons, armor families and cross-slot kits with visible partial/full stat bonuses.

## Scope

- Add exactly 13 authored Mantok set families and their set-piece item contents.
- Compute active thresholds from equipped item ids through shared equipment/effective-stat helpers.
- Support arbitrary thresholds such as `2/2`, `2/3`, `3/3`, `2/4`, `3/4` and `4/4`.
- Keep every live set bonus stat-only in this foundation slice.
- Show static set membership/progress in item descriptions and live equipped progress/active/next bonuses in item and equipment surfaces.
- Merge set-piece monster loot into existing level `9..13` monster loot without replacing trophy, fallback or Mantok coverage loot.
- Update focused tests, balance notes, lore/current context and manual QA surfaces.

## Non-goals

- No gear-action buttons.
- No bleed, burn or combat status runtime.
- No borrowed class/race abilities.
- No Yeger disguise, service discount or economy perks.
- No Shynok, Kosti, table-games, shops, market, trading, crafting UI, Prisma migration or level-cap change.
- No broad combat formula rebalance.
- No production flag or `/dev_*` helper: this slice adds content, presentation and stat aggregation only, with no new timer, cooldown, retry, once-per-period gate or mutable runtime loop.

## Acceptance criteria

- Exactly 13 authored set families ship.
- Every set piece validates against `itemSchema`, has a unique id and includes `Частина комплекту «...»: N/total.` in the description.
- Every 3+ piece set has a small stat-only 2-piece bonus.
- Paired daggers activate at `2/2`.
- A 4-piece armor family activates partial and full thresholds.
- Multiple simultaneous sets stack deterministically.
- Replacing/removing equipment updates active set bonuses.
- Set stat bonuses affect effective stats once and only at active thresholds.
- Runtime loot includes set pieces while preserving existing trophy/fallback/coverage loot.
- Item and equipment presenters show progress, active bonuses and next bonuses.
