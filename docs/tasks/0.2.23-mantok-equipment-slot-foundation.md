# 0.2.23 - Mantok Equipment Slot Foundation

## Goal

Split the current small equipment shell into explicit manatka equipment slots without doing the larger global item rebalance yet.

This slice prepares the content, service and Telegram surfaces for future offhand/tool/legs work while keeping existing player equipment readable and safe.

## Scope

- Define canonical equipment slots: weapon, offhand, head, chest, legs, accessory and tool.
- Add explicit item content metadata for equipment slot eligibility.
- Keep legacy `armor` equipment rows readable as the canonical `chest` slot.
- Preserve existing item ids, inventory rows, equipment replacement rules and protected-transfer behavior.
- Update inventory/equipment filter buttons, item-detail equip copy and equipment result copy so players can see slot and replacement consequences.
- Route generated tool-category loot to the new `tool` equipment slot without changing its drop/effect balance.

## Non-goals

- No global item stat, rarity, value or reward-table rebalance.
- No two-handed/offhand conflict model beyond defining the offhand slot.
- No new Prisma migration.
- No new shops, crafting, sales, trading, gift, remort or Mantok Chest rules.
- No new player reward, achievement, lore route or combat power behavior.

## Acceptance Criteria

- Content validation accepts only supported equipment slots and rejects equipment-slot metadata on non-equippable items.
- Existing starter equipment declares explicit slot metadata and still equips as before.
- Legacy stored `armor` rows render and unequip through `chest`, while new equips write canonical slots.
- `/equipment`, inventory slot filters and item-detail cards expose the expanded slot set and replacement summary.
- Old callback payloads continue to parse safely where practical, and new callback payloads cover every canonical slot.
- Loot Expansion v1 tool manatky use the `tool` slot foundation without rebalancing generated gear.
- Existing equipped/protected item transfer, Mantok Chest, sale, remort and inventory behavior remains unchanged.
