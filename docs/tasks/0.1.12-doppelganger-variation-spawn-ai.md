# 0.1.12 — Doppelganger Variation, Spawn Factory and Skill Replies

## Goal

Make the training doppelganger feel less deterministic while preparing the safe parts of the larger doppelganger improvement pack.

## Scope

- Add a categorized Ukrainian doppelganger line pool with deterministic selection, placeholders and recent-line anti-repeat.
- Use the line pool for `/spar` spawn copy and counter flavor.
- Preserve doppelganger combat identity, passive copied equipment summaries and debug trace in the combat state.
- Add `COPY_TARGET`, `RANDOM_BUILD`, champion fallback and `WEIGHTED_RANDOM` spawn mode plumbing without adding persistence.
- Add random-build generation from valid race/class/pronoun choices plus combat-only passive gear.
- Let doppelganger monsters answer with class-shaped skill replies and turn debug trace.
- Keep `/spar` defaulting to `COPY_TARGET`.

## Non-goals

- No champion snapshot persistence.
- No persistent item copies, inventory mutation, drops or new economy grants.
- No active equipment ability system beyond existing passive item effects.
- No broad PvP, group combat, raids, markets, crafting or Mini App UI.

## Acceptance Criteria

- Repeated doppelganger line selection varies across seeds and avoids recent line ids when possible.
- Placeholders render without raw ids, `undefined`, `null` or unreplaced braces.
- Copy-target spawn preserves passive equipment effects in combat stats and records an ephemeral copied-equipment summary.
- Random-build spawn produces a valid race/class/pronoun/level combo and combat-only passive gear.
- Stored combat state can reconstruct the doppelganger combat stats for later turns.
- Doppelganger monsters can use class-shaped skill replies and expose the chosen ability in debug trace.
- Focused domain, service and presenter tests cover the changed behavior.
