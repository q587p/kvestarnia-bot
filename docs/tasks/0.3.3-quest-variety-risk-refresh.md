# 0.3.3 Quest Variety and Risk Refresh

## Goal

Refresh existing quest variety without adding new quest engines: make Adventure Choice method help preserve real risk/reward tradeoffs, expand Daily Korchma Round scene variety, and add more authored starter cellar mouse outcomes.

## Scope

- Add a reusable quest risk-band helper to keep safe/steady/risky/wild methods from all presenting as near-certain.
- Keep Adventure local-failure rewards at `0 XP / 0 gold / no item / no fight`, and keep fight-handoff reward semantics unchanged.
- Add the method-help memo: safer is calmer, riskier is richer, exact odds stay hidden.
- Expand Daily Korchma Round content from 13 to 36 scenes while preserving one Kyiv-day offer, 3 offered scenes, complete any 2, explicit Quest Table turn-in, no checks, no combat, no items, no schema.
- Add authored cellar mouse scene methods/outcomes while keeping the level 2-3 gate, cooldown, replay, active-combat/pending-raid guards, transaction safety, and tiny reward envelope.

## Non-goals

- No new combat, class abilities, raids, shops, achievements, or Telegram routes.
- No changes to Daily Korchma Round rewards or persistence model.
- Local `/dev_reset_cellar_mouse` clears the repeatable cellar mouse cooldown and grownup mouse roleplay cooldown for the current character, so manual QA can sample the refreshed level 2-3 mouse outcomes and inspect the level 4+ retry text without waiting. It stays behind the existing non-production dev grant gate.
- Follow-up exception: the current PR also narrows Yeger paid-bandage daily-limit queries and adds a `DailyAction(characterId, key, createdAt)` index migration to keep the existing `🩹 Бинти` purchase flow responsive on small Render instances. It does not change player-facing Yeger copy, prices, limits, rewards, routes, or callbacks.

## Acceptance Criteria

- Representative 5-method Adventure help cards have at most one `майже надійно` row, at most two `добрі шанси` rows, and at least two `непевно` / `дуже непевно` rows.
- Safer/paid/modest methods remain lower-reward; generous, injury, fight, deception, unstable, and local-failure methods cannot look as reliable as safe methods.
- Daily Korchma Round content has yard scenes plus multiple interior location groups, unique scene/action ids, exactly 3 actions per scene, and deterministic authored outcomes.
- Cellar mouse has 13+ new authored outcome lines, and new methods are reachable only through the current visible-method allowlist.
- No achievement update: the player discovers no new action surface, milestone, reward, or route; only existing method/content variants changed.
- Lore board reviewed: no lore update needed because no current in-world fact, location, class, item, or system behavior changed.

## Manual Telegram QA

1. Run `refresh-local-bot.cmd` before manual testing from the isolated local bot snapshot.
2. Open `Три справи`, choose an Adventure problem, open `💡 Підказка`, and verify the method list has mixed qualitative risk labels plus the compact memo and no exact odds/rewards.
3. Complete one safe-ish and one risky Adventure method; verify local failure still gives no reward/fight and fight handoff still starts the existing fight path without immediate reward.
4. Open Daily Korchma Round across several reset days; verify 3 scenes appear, each scene has exactly 3 actions, completed scenes freeze, and the final Quest Table turn-in remains explicit.
5. At level 2-3, open the cellar mouse errand repeatedly after `/dev_reset_cellar_mouse`; verify varied authored replies, tiny rewards, stale hidden method callbacks, duplicate taps, active combat, and pending raid guards. At level 4+, use the same helper to reopen grownup mouse roleplay retry text without waiting.
6. For the Yeger follow-up, open `🩹 Бинти`, preview `93 бинти`, cancel, confirm an affordable bundle, and verify the UX/copy stays unchanged while slow-route logs appear only for slow requests or with `YEGER_PERF_DEBUG=1`.
