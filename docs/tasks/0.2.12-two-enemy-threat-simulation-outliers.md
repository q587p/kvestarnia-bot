# 0.2.12 - Two-Enemy Threat Simulation and Targeted Outlier Tuning

## Goal

Use deterministic combat simulation to measure the current two-enemy threat escalation pressure, then make small targeted tuning changes for the worst 0.2.11 outliers without changing rewards, persistence schema or player-facing reward promises.

## Scope

- Extend `simulate:combat` with an explicit one-enemy vs two-enemy threat encounter mode.
- Allow simulator sweeps over every active onboarding race and aggregate by level, class and race.
- Allow focused simulator probes to model remort memory with `--remort N`.
- Count all stored per-enemy actions in simulator summaries.
- Add a small production guard for backup enemies in two-enemy fights:
  - backup monsters enter threat fights with reduced HP;
  - while both enemies live, backup enemies skip alternating pressure turns;
  - backup response damage is reduced while they are an additional living enemy.
- Tune the strongest observed authored outliers:
  - `monster.zero-declaration-tax-dragon`
  - `monster.siege-iron-varenyk`
  - soft race/class pairings around Bisyny and Molfar Soul.

## Non-Goals

- No new monster pools, loot tables, XP/gold formulas, quest progress rules or threat-history persistence.
- No schema, migration, remort-state or reset-flow change.
- No achievement hook: this slice adds no new visible player action, milestone or durable odd outcome.
- No bot `/dev_*` command: this slice adds simulator tooling and runtime tuning only, not a new cooldown, once-per-period gate, random offer or pending gameplay loop.
- No broad class rebalance after the 0.2.11 class pass.

## Acceptance Evidence

- One-enemy baseline stayed healthy after tuning:
  - `npm.cmd run simulate:combat -- --levels 3-13 --monster-levels same --runs 30 --classes all --race race.human-ish --policy aggressive --max-turns 24 --encounter one-enemy --seed 0.2.12-final-humanish-one`
  - Result: 85.9% wins, 12.6% losses, 5.7 average turns.
- Two-enemy threat no longer collapses into a near-zero win-rate death spiral:
  - `npm.cmd run simulate:combat -- --levels 3-13 --monster-levels same --runs 30 --classes all --race race.human-ish --policy aggressive --max-turns 24 --encounter two-enemy-threat --seed 0.2.12-final-humanish-two`
  - Result: 48.1% wins, 46.9% losses, 6.5 average turns.
- All-active-race compact two-enemy sweep remained intentionally dangerous while exposing weak bands:
  - `npm.cmd run simulate:combat -- --levels 3-13 --monster-levels same --runs 10 --classes all --races all --policy aggressive --max-turns 24 --encounter two-enemy-threat --seed 0.2.12-final-race-sweep-two`
  - Level aggregates ranged from 31.7% to 64.7% wins.
  - Class aggregates ranged from 29.4% Ranger to 66.4% Varenyk-mancer.
- Targeted outlier probes improved without making every matchup trivial:
  - `monster.zero-declaration-tax-dragon`: roughly 37.2% to 73.1% wins in the focused same-level matrix.
  - `monster.siege-iron-varenyk`: roughly 49.7% to 78.0% wins in the focused same-level matrix, though average turns remain longer than ordinary fights.
- Follow-up `monster.inventory-prophet` probe for a level 12 hero with five remorts:
  - `npm.cmd run simulate:combat -- --levels 12 --monster-levels same --runs 100 --classes all --race race.human-ish --policy aggressive --max-turns 24 --encounter one-enemy --remort 5 --seed prophet-l12-r5-humanish`
  - Result: all human-ish class matchups won; slow support/control rows remained visible at roughly 5.5-7.0 average turns.
  - Inline all-active-race R5 matrix found `100.0%` one-enemy wins and `99.8%` two-enemy threat wins for rows where `monster.inventory-prophet` was primary, with worst two-enemy rows feeling long rather than blocked.
