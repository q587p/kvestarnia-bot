# 0.2.31 - Polish, Bugfixes and QA Hardening

## Goal

Reserve the next version slot after `0.2.30` for a narrow polish and bugfix pass driven by post-merge review, CI, manual Telegram QA and player-facing rough edges.

## Scope

- Fix regressions found after the current release candidate lands.
- Prioritize Mantok Ability Grants QA hardening if gear-action manual QA, stale callback UX, achievement timing, journal replay or Big Barrel / turn-based duel edge cases still need proof.
- Tighten Telegram callback UX, stale/replay handling, presentation copy, keyboard shape and card readability where existing shipped flows are unclear.
- Add focused regression tests for every runtime bug fixed in this slice.
- Update release surfaces only for the actual fixes that ship in this version.

## Non-goals

- No new broad gameplay systems.
- No shops, crafting, markets, item-instance migration, Prisma schema changes or economy expansion unless a blocking bug proves a tiny fix is required.
- No balance rework beyond clearly documented bug fixes or obvious outliers discovered during QA.
- No hidden procs, generated ability loot or unrelated feature carry-over.

## Acceptance criteria

- Bugs addressed in this slice have narrow tests or a clear explanation for manual-only coverage.
- Player-facing Ukrainian copy stays short, truthful and aligned with the visible behavior.
- The branch is current with `main` before handoff and has no unresolved merge conflicts.
- `CHANGELOG.md`, `news.md`, `docs/ai/context.md` and this task doc match the final shipped behavior if runtime behavior changes.

## Shipped fixes

- Big Barrel Brother raid gear-action settlements now return first-use achievement unlock notifications to the acting participant and to refreshed participant cards.
- Turn-based duel committed gear-action rounds now return first-use achievement unlock notifications to the acting participant and other participant refreshes.
- Stale, duplicate, no-mana, cooldown, missing-grant and queued-only gear callbacks remain non-mutating and do not create early or duplicate achievement notifications.
- Unknown or stale Telegram callbacks now answer with the existing invalid-button alert instead of silently blinking; `👀 Хто поруч` -> `🗡️ Тиха кишеня` has direct callback coverage.
- Active Barrel cards no longer decorate `⬅️ До зали` as a quest route when the only outstanding marker is the Barrel tutorial step already available at the Barrel.
- The Barrel tutorial accept result now decorates the direct `🛢️ До Бочки` CTA with the quest marker, so taking `Бочка, або Туди і звідти` points toward the Barrel immediately.
- Shynok problem-paper issue results now rebuild quest markers after the paper is issued, so `⬅️ До зали` marks other available Korchma-location quests with fresh state.
- Race- and class-personalized adventure problem titles and hooks now lowercase identity forms and avoid quoted name insertions, e.g. `Портрет раси ельфа` and `Іспит для злодія`.
- Generated Loot Expansion enhancement prices now use a soft cap to keep high-base `+4`/`+5` manatky from creating runaway `goldValue` and sale/exchange pressure, without changing combat stats, rarity, level gates or drop odds.
- Persistent one-enemy PvE fights, including Yeger contracts, now apply combat-only remort-aware monster pressure after the third remort; two-enemy threat backup monsters receive a capped pressure guard while primary enemies stay authored.
- Ordinary Nyz two-enemy threat escalation now lowers the consecutive eligible-win gate by current remort life: three wins at base life, two after one remort, and one after two or more remorts.
- Korchmar problem-chain counters now filter persistent fight wins by the character's current remort life, preserving legacy zero-remort wins while preventing old pre-remort victories from completing a fresh problem paper.
- Latest Events now record completed solo Barrel raid wins and Big Barrel Brother group raid wins/losses as raid rows under the existing `⚔️ Бої` filter; only group raid victories are high severity and appear under `⭐ Важливе`. New public level-up rows include the character's remort life tag, such as `(р5)`, after the reached level.
- Completed Big Barrel Brother result cards opened by non-participants now show the total raid XP, gold and item grants as `Загальна винагорода рейду` without assigning them to a specific participant; participant cards label the personal payout as `Ваша винагорода за рейд`.
- Big Barrel Brother victory settlement now grants each meaningful participant one deterministic generated manatka from the Loot Expansion pool using the frozen participant level/class/race profile, instead of replaying the solo Barrel starter bundle for every participant.
- The `👤 Персонаж` card now exposes `🛡️ Спорядження` as an inline action above achievements/titles and recovery actions, opening the existing equipment screen without going through inventory first; the persistent main menu keeps the previous compact layout.
- Outside-Korchma quest gates now keep `🚪 Зайти в корчму` unmarked unless a real quest marker snapshot confirms active work inside, so a cooldown-only cellar errand does not imply available quests.
- Direct `/tavern` hall cards now resolve the same quest marker snapshot as place callbacks, so available Korchma quests keep their `⚠️` marker after opening the hall by command.
- Hall `📋 Стіл зі справами` buttons no longer duplicate `⚠️` for quests already visible on final location buttons in the same hall keyboard, such as `🐭 Льох ⚠️`; table-only quests still mark the table.
- Quest Table cards now treat the rendered card as the current `📋 Стіл зі справами` location, so `🍺 До зали` stays unmarked when the only available quest actions are already visible on that table card.
- Yeger-corner `🛢️ До Бочки` return buttons now mark the route when another active quest is beyond the hall at the quest table, Shynok or cellar, while ignoring the visible Yeger quest on the current card.
- Old Shynok table-game links now show stored completed game results, or a clear not-started/refunded card when the table closed before play.
- `🎒 Манатки` now shows received-date and name sort toggles when the visible list has multiple items, and preserves the chosen order through pagination, page prompts, item detail back links and filtered views.
- Item detail replacement previews now show the current item's visible effect beside the `Замінить` name, so same-slot equipment swaps are easier to compare before committing.
- Postal delivery now allows multiple outgoing pending packages from the same sender when their reserved item ids do not overlap; a second package that tries to reuse an already reserved item id still stales before charging another delivery fee.
- Outside the documented Big Barrel Brother group-victory item grant correction, cooldown values, ability families, Yeger progress, remort XP math and Prisma schema did not change in this polish slice.
