# 0.2.9 - Daily Korchma Rounds

## Goal

Add one low-pressure, once-per-Kyiv-day route for level 3+ players: show three authored absurd Korchma incidents in three locations, let the player complete any two, then require an explicit return to the Quest Table for one small replay-safe reward.

## Activation prerequisite

Activated from current `main` after `0.2.8` Achievements and Cosmetic Title Records. Do not combine the daily route with item-use, Bard Performance, broad achievement work or another runtime slice.

Canonical design: `docs/DAILY_KORCHMA_ROUNDS.md`.

## Scope

- Player-facing name: `Корчмарський обхід`; flavor label: `Ревізія здорового глузду`.
- Level gate: 3+.
- One calendar-day offer keyed by `Europe/Kyiv`, with lazy rollover and no scheduler.
- Persist the generated offer the first time it is opened for the day.
- Offer exactly three unique authored scenes:
  - one scene at new public location `location.korchma.yard` / `Задвірок корчми`;
  - two scenes at two different existing interior locations.
- Ship the 13-scene v1 content pack from the canonical design.
- Complete any two unique scenes; after `2/2`, block the omitted third scene.
- A scene completes only from its required current presence location.
- Each scene offers exactly three authored actions and one deterministic authored outcome per action.
- Steps grant no XP, gold, items, HP/mana change, combat, cost or stat check.
- Final reward requires an explicit Quest Table turn-in and is fixed at `4 XP + 2 gold`, once per Kyiv day.
- Integrate daily status and navigation into the existing Quest Hub and contextual location surfaces.
- Preserve existing combat-lock, pending-Barrel, presence, replay and remort contracts.
- Add a narrow non-production reset helper only if it materially improves manual QA and stays outside production.

## Persistence contract

Use the existing `daily_actions` ledger; no Prisma schema or migration change is expected.

Suggested keys and local-date identities:

```text
key = quest.korchma-round.offer
localDate = <YYYY-MM-DD Kyiv day>
reward = 0 / 0

key = quest.korchma-round.step
localDate = <YYYY-MM-DD Kyiv day>:<sceneId>
reward = 0 / 0

key = quest.korchma-round.reward
localDate = <YYYY-MM-DD Kyiv day>
reward = 4 XP / 2 gold
```

Persist compact versioned `resultJson`:

- offer: content version, day key, three scene IDs and generated order;
- step: scene ID, action ID, location ID, outcome ID and life/remort audit;
- reward: completed scene IDs, omitted scene ID and content version.

The service must authorize from persisted state. Keyboard visibility is not authorization.

## Time contract

- Add a pure DST-safe Kyiv date helper using `Intl.DateTimeFormat(..., { timeZone: "Europe/Kyiv" }).formatToParts()` or an equally dependency-free, testable approach.
- Do not use UTC `toISOString().slice(0, 10)` for this daily identity.
- Do not modify the existing 93-minute Adventure period helper or semantics.
- Old-day callbacks are stale no-ops and route to the current daily overview.
- No countdown is required.

## Remort contract

- Do not add the new daily keys to `REMORT_RESET_DAILY_ACTION_KEYS`.
- Offer, completed steps and claimed reward survive remort within the day.
- Include a compact life token on mutating callbacks so a card rendered before remort becomes a stale no-op.
- A fresh post-remort overview may continue the same persisted day progress.
- Remort must never create a second final reward.

## Location contract

Add `PRESENCE_LOCATION_KORCHMA_YARD = "location.korchma.yard"`.

- Public title: `Задвірок корчми`.
- Region: `Корчма Квестарні`.
- Names may be shown under the existing presence privacy rules.
- The yard is outside, not part of `KORCHMA_INTERIOR_LOCATION_IDS` and not accepted by `isKorchmaInteriorLocation()`.
- Add movement copy, current-location routing, a return to `Перед корчмою`, and any required public-location grouping/tests.
- Do not expose the yard as permanent level 1-2 clutter; contextual level 3+ daily navigation is sufficient.

## Bot flow

1. Quest Hub shows locked, `0/2`, `1/2`, turn-in-ready or completed state.
2. Daily overview shows the three scenes, their locations and status without exact future reward.
3. Selecting an incomplete scene routes to or opens its location; it does not complete remotely.
4. At the required location, open the scene and choose one authored action.
5. First unique step becomes `1/2`; duplicate callbacks replay without mutation.
6. Second unique step becomes `2/2`; the third scene becomes `Не сьогоднішня катастрофа`.
7. Player returns to the Quest Table and explicitly claims.
8. Result shows exact `+4 XP` and `+2 gold`; repeated claim replays the stored result.

Keep Telegram messages compact and all player-facing copy Ukrainian.

## Non-goals

- No daily checklist over fights, gifts, sales, drinks, inventory or consumables.
- No mandatory combat, another player, purchase, item use or resource spend.
- No stat rolls, grades, injuries, fight handoff, item drop or class/race power modifier.
- No streak, calendar collection, missed-day debt, catch-up, reroll or third-step bonus.
- No notification scheduler.
- No broad Korchma layout rewrite.
- No 93-minute Adventure refactor.
- No separate achievements project, season pass, Mini App or new Prisma model.
- Do not reuse Shynok beer-round achievement ids for this route; add narrow daily-round hooks/definitions or document a precise follow-up if no durable event exists.
- No item-tag / one-use-manatka behavior in this release.

## Acceptance criteria

- Level 2 is locked; level 3+ receives one stable offer for the current Kyiv date.
- Reopening/restarting/redeploying preserves the exact three persisted scenes and order.
- Every offer has exactly one yard scene and two different interior locations.
- All 13 v1 scenes and their three actions pass content validation.
- Any two unique scenes are sufficient; the third cannot mutate after `2/2`.
- A scene cannot complete from a different location, from an unknown offer, with an unknown action, on an old day or from an old-life callback.
- A duplicate step never creates another row or reward.
- Final claim is denied before `2/2` and outside the Quest Table.
- Final claim grants exactly `4 XP + 2 gold`, no item, once; replay and restart return the stored result.
- Remort cannot clear progress or duplicate the reward.
- Active combat and pending-Barrel guards prevent daily mutation.
- The yard is a correct public outside location with working entry/return/current-location/online behavior.
- Existing Adventure, fight, Yeger, Shynok, cellar, problem-chain and presence flows retain behavior.
- No Prisma schema or migration is changed.
- Focused tests and the full required checks pass.

## Implementation notes

- Status: implemented for `0.2.9` on branch `codex/0.2.9-daily-korchma-rounds`.
- Persistence: reused `daily_actions` for versioned offer, step and reward rows; no Prisma schema or migration was needed.
- Reward: final Quest Table turn-in grants exactly 4 XP and 2 gold once per Kyiv day.
- Remort/restart: same-day rows are intentionally retained, and mutating callbacks carry a compact life token so old-life buttons become stale.
- Achievement: added rewardless `achievement.quest.daily-korchma-round` and the `daily.korchma-round.completed` event hook instead of reusing Shynok beer-round ids.
- Dev helper: no separate production-facing command was added; focused service tests cover deterministic reset-style setup without weakening runtime rules.
