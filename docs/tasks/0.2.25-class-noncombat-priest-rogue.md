# 0.2.25 — Class Noncombat Priest/Rogue

## Goal

Ship the first noncombat class identity actions for level 3+ Priest and Rogue:

- Priest direct aid outside combat: self/nearby heal and direct blessing.
- Rogue same-location risky pickpocket: tiny bounded gold theft with replay-safe stored outcome.

These are not combat class ability changes and do not rebalance `src/content/playerAbilities.ts`.

## Scope

- Add narrow Prisma tables for Priest aid actions, Priest blessings and Rogue pickpocket attempts.
- Add a class noncombat domain/service/repository slice without a universal technique engine.
- Surface actions through `Хто поруч` / same-location presence:
  - `✨ Жрецька поміч` for eligible Priests, including self-heal/self-bless when alone.
  - `🗡️ Тиха кишеня` for eligible Rogues when another active same-location target exists.
- Target lists use exact normalized same-location semantics for this MVP; legacy aliases that normalize to the same actionable location are included, but broader front/hall-style grouping is not treated as actionable.
- Recheck actor/target class, level, remort life, location, activity and active blocking flows at mutation time.
- Use a 93-minute same actor-target repeat wait for Priest blessing and a 93-minute actor-scoped finger-rest cooldown for Rogue pickpocket. Priest healing is limited by missing HP and mana, not cooldown.
- Store Rogue attempts once per actor-target Kyiv day and replay duplicates without rerolling.
- Add rewardless achievements backed by durable rows.
- Update `📖 Перекази` class entries for Priest and Rogue.

## Decision Changes

- Priest help is direct in this MVP. There is no accept/decline offer flow; successful aid sends a private best-effort notification after durable mutation.
- Rogue player-targeted gold theft is allowed only in this bounded MVP:
  - same active location;
  - target level 3+;
  - once per actor-target Kyiv day;
  - 93-minute actor finger-rest cooldown after every resolved attempt;
  - 1-13 gold max and never more than target balance;
  - no item theft, public shame row, quest/combat progress or extra caught cooldown.
- Noticed successful Rogue thefts tell the target clearly that gold was stolen but the Rogue was seen, and attach a private one-button safe quick-duel retaliation that is bound to the stored pickpocket attempt, expires after a short window, auto-accepts from the Rogue and has no health warnings, stakes, gold/item loss or quick-duel XP.
- Priest blessing ships as a durable visible 13-minute timed status with a small `+1..+5 luck` bonus based on Priest intelligence plus actor/target level difference, stored as `bonusStat = "luck"` / `bonusAmount`, and shown on the hero card while active.
- Priest/Rogue noncombat planning uses the canonical effective character summary path, including equipped manatky and active non-expired Priest blessing bonuses where relevant. Stored `statSnapshotJson` / result snapshots reflect the same effective inputs that drove the calculation.
- Local `/dev_reset_priest_blessing`, `/dev_reset_quiet_pocket` and `/dev_reset_rogue` helpers ship for manual QA of the new class cooldown gates. The Priest helper clears legacy cooldown rows, active direct blessings and same-target blessing waits. `/dev_reset_quiet_pocket` clears the current `noncombat.rogue.pickpocket` cooldown key plus legacy quiet-pocket keys for compatibility. `/dev_reset_rogue` clears that Rogue cooldown family and forgets the current actor's Rogue pickpocket attempts for the current Kyiv day so the same targets can be tested again. They are non-production grant commands: production config must not register, show or mutate through them.

## Acceptance Criteria

- Priest heal:
  - applies the preserved formula, with mana cost scaled from actual HP restored: minimum 1 for any healing, capped at 13 around a 42 HP heal;
  - calculates Priest stats and target HP maximum from canonical effective summaries, including equipped manatky and active non-expired Priest blessing bonuses;
  - cannot overheal or heal full HP;
  - spends mana only on successful healing and does not start a cooldown;
  - notifies another healed target privately after durable mutation.
- Priest blessing:
  - spends 8..23 mana by granted bonus amount and starts the same-target repeat wait only on successful blessing;
  - creates one 13-minute visible blessing with a small `+1..+5 luck` bonus;
  - calculates bonus strength from canonical effective Priest stats and exposes the same non-expired bonus through the hero summary without stacking;
  - blocks already-blessed targets;
  - blocks only the same actor-target pair during the 93-minute repeat wait; other targets remain available while mana lasts;
  - notifies another blessed target privately after durable mutation.
- Blocked Priest no-op heal, same-target blessing wait and already-blessed result cards keep the Priest action keyboard attached so the player can choose another available action or refresh; full-HP, target-wait and repeated-blessing blockers use reason-specific headings.
- Priest self-heal buttons hide while the character is already at full HP, matching medical-item no-op surfacing on the character card.
- Priest/Rogue open cards hide action buttons while the actor is already in combat or raid; stale callbacks explain the real active-flow blocker without generic protocol wording. Scene/adventure presence alone does not block class noncombat actions.
- Rogue pickpocket:
  - enforces same-location active target gates and target level protection;
  - calculates Rogue power/bonus from canonical effective stats, including equipped manatky and active non-expired Priest blessing bonuses;
  - keeps targets already attempted by this Rogue on the current Kyiv day visible with a tomorrow-only marker instead of a pickpocket action;
  - transfers gold atomically on success and caps stolen gold by target balance;
  - stores empty/no-op attempts safely when target has no gold;
  - stores caught-badly attempts and sets Rogue HP to 0;
  - replays duplicate/stale callbacks without rerolling or double transfer, even if live location has drifted after the stored attempt.
  - sends a fresh noticed-success target notification with a target-only instant-retaliation duel button.
- Achievements:
  - first Priest heal;
  - first Priest blessing;
  - first Rogue pickpocket attempt;
  - first successful Rogue pickpocket;
  - first caught-badly outcome.
  - actor notifications are sent only for fresh completed actions/attempts, not for blocked/no-op states or duplicate Rogue replay.
