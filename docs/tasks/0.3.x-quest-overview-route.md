# 0.3.x - Quest Overview Route

## Goal

Turn `🗺️ Квести` into a compact quest overview/journal instead of a duplicate opener to the current Quest Table.

## Scope

- Show current available quest surfaces and active progress:
  - starter routes;
  - Daily Korchma Rounds;
  - Yeger boards;
  - Barrel Beer Tutorial;
  - current problem chain;
  - relevant completed/locked notes.
- Keep direct route buttons to the appropriate place.
- Preserve existing quest-table behavior.
- Keep markers/icons consistent with `questButtonMarkers`.

## Non-goals

- No new quest engine.
- No new quest rewards.
- No broad journal/history.
- No automatic navigation that mutates progress.
- No Mini App.

## Acceptance criteria

- `🗺️ Квести` gives a useful overview from anywhere safe.
- Active combat/raid blockers keep existing behavior.
- Direct buttons route to existing surfaces.
- Existing quest callbacks remain compatible.
- New overview copy is short enough for Telegram.

## Focused tests

- main menu keyboard;
- quest overview presenter;
- quest marker snapshot;
- active combat/raid blockers;
- direct route buttons;
- `npm run check`.

## Manual Telegram QA

- Fresh level 1.
- Level 2 with Barrel Beer Tutorial.
- Level 3+ with active adventure/problem chain.
- Yeger started/completed states.
- Active fight/raid blocker.
