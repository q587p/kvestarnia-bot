# 0.3.4 - Quest Overview Route

## Goal

Turn the persistent `🗺️ Квести` button into a compact quest overview/journal route instead of another opener for `📋 Стіл зі справами`.

## Scope

- Render a read-only `🗺️ Квести` overview from the current quest snapshot.
- Show compact status rows for starter shawarma, starter fight, cellar/grownup mouse, Daily Korchma Round, Adventure Choice / `Три справи`, current Korchmar problem chain, Yeger boards, Barrel Beer Tutorial, Charkokovalnia unlock, and relevant locked/completed notes where available.
- Each row should carry progress, what is already done when available, next-step guidance, and a location/turn-in hint in text.
- Prioritize rows as claimable, active progress, available, locked, completed.
- Keep the existing `/quest`, physical `Стіл зі справами`, `v1:quest:list`, and Quest Hub archive behavior.
- Keep overview buttons navigation-only: `📋 До Столу зі справами`, optional refresh, and hall/back navigation. Do not add per-quest direct route buttons from overview rows.

## Non-goals

- No new quest engine, journal archive, rewards, schema, migrations, public feed rows, combat rebalance, Mini App, or Yeger/Adventure/Daily reward changes.
- No new achievement: this is a UX/readability route over existing gameplay.
- No new `/dev_*` helper: the slice adds no timer, cooldown, random offer, pending session, retry, once-per-period gate, or wait rule.
- No lore-board update: the shipped in-world behavior of quest systems is unchanged; only the navigation overview changes.

## Acceptance criteria

- `🗺️ Квести` shows a useful overview from safe Korchma states and does not stamp quest-table presence.
- Outside-Korchma, no-character, active combat, turn-based duel, pending/active Big Barrel, active passage-search and stale callback blockers keep existing behavior.
- Overview buttons are navigation-only; per-quest locations are mentioned in text rather than offered as direct route buttons.
- Quest Table and archive callbacks remain compatible.
- Overview text is Ukrainian, compact, HTML-escaped and under Telegram callback-size limits.

## Manual Telegram QA

1. Fresh level 1: open `🗺️ Квести`; verify starter guidance and no broken buttons.
2. Level 2: verify starter/cellar mouse and Barrel Beer Tutorial guidance.
3. Level 3+: verify Daily Korchma Round row and Adventure / `Три справи` row.
4. Active Daily Korchma Round 1/2 and 2/2: verify overview progress, done-scene text, next-step text and location/turn-in hints without a direct `До обходу` button.
5. Yeger not started / in progress / completed: verify row state, progress and location guidance without a direct `До Єгеря` button.
6. Barrel Beer Tutorial available / in progress / turn-in-ready: verify the overview explains table, Бочка and Shynok steps in text only, while the keyboard stays navigation-only.
7. Active solo combat, active turn-based duel, active/pending Big Barrel and active passage search: verify existing blockers win over overview.
8. Stale `v1:quest:overview` callback: verify it fails closed or routes to the current canonical overview without mutation.
9. Verify opening overview does not complete, claim, accept, start fights, start raids, move presence to `Стіл зі справами`, or expose per-quest route buttons such as `До Низу`, `До Єгеря`, `До бочки`, `До шинку`, `До льоху`, `До задвірка`, `До Корчмаря`, `До обходу`, or `До Трьох справ`.
