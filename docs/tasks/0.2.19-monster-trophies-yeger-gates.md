# 0.2.19 - Monster Trophies And Yeger Supply Gates

## Goal

Ship concrete runtime trophy coverage for the active monster roster and lock Yeger bandage supplies behind completed Yeger quest progress.

## Scope

- Add at least one concrete runtime trophy item for every active monster in `src/content/monsters.ts`.
- Keep new trophy items low-power and mostly `junk`/`cosmetic`, with Ukrainian Kvestarnia item names/descriptions.
- Derive Bestiary possible trophy hints from the runtime `getLootCandidates` path.
- Hide `🩹 Бинти` in the Yeger corner until the first Yeger board is completed.
- Block direct/stale paid preview, paid confirm/cancel and Ranger free-bandage callbacks before the first `5` unquiet wins are turned in.
- Name the second `17`-target Yeger board distinctly as `Неспокійні справи 2.0` and point first-board completion toward ordinary Yeger bandages plus the next board.
- Document that future `Щільний бинт` and `Польова аптечка` work is gated behind the second `17` unquiet target board.

## Non-goals

- No new Yeger tag-hunt UI, tracking mode, quest stage or `tagsAny` selector behavior.
- No guaranteed drops, collection tracking, shops, crafting, trading, broad economy rebalance or new combat behavior.
- No runtime dense bandage or field-kit implementation in this slice.
- No Prisma schema or migration.

## Acceptance Criteria

- Every active monster id has a non-empty runtime loot mapping.
- Every monster loot item id exists in `items`.
- Trophy-covered monsters include a reachable trophy candidate and reachable non-trophy fallback candidates of compatible rarity, with the default concrete trophy candidate weighted around `23%` of successful monster-specific item drops.
- Bestiary trophy hints map to items reachable through `getLootCandidates`.
- Pre-completion Yeger bandage preview/confirm/cancel/free paths return locked copy without spending gold, granting items, creating previews or setting cooldowns.
- First-board completion mentions opened ordinary Yeger bandages and the second board, while the second board renders as `Неспокійні справи 2.0`.
- Basic paid and Ranger bandage behavior still works after the first Yeger board is completed.
- Future advanced supply docs explicitly require the second `17`-target Yeger board.
