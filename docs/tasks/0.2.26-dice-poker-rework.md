# 0.2.26 — Dice Poker Rework

Status: implemented in PR, release-hardening in progress. Manual Telegram QA remains a release blocker.

## Goal

Replace the confusing old `🎲 Кості` style/sign table UI with a clear Dice Poker feature under the existing Shynok `🎲 Кості` / social-games entry point.

The old turn-based duel/tournament reward idea is deferred to `0.2.27+` or later. This slice ships no tournament claims, no public shame feed, no item loss, no paid power and no Mini App/admin UI.

## Shipped Scope

- `🎲 Кості` now opens `🎲 Кості й покер` with:
  - `⚡ Швидкі кості`;
  - `📜 Табличні кості`;
  - `❔ Правила`.
- Quick mode supports real 2-8 player social tables and an explicit fallback duel vs the existing Doppelganger opponent:
  - the fallback is available through the separate Shynok `🪞 Допельґанґер` table-games branch from 23:00 until 07:00 Kyiv time; daytime keeps the Doppelganger in the Fighting Corner and hides that branch;
  - five fair d6 per side;
  - one optional player reroll by selected dice;
  - deterministic NPC reroll heuristic only in the Doppelganger fallback;
  - explicit five-dice poker evaluator and tie-breakers;
  - exact equal hands in the Doppelganger fallback start deciding rounds, capped at three draw rounds before refund/close;
  - exact equal social quick hands refund the shared table safely;
  - social quick tables arm a short auto-start deadline after the second player joins, stay joinable until they start or fill to 8/8, and auto-finish unresolved quick rounds as no-reroll hands after the round deadline.
- Scorecard mode supports real social tables for 2-8 players:
  - 13 turns;
  - initial roll plus up to two selected-dice rerolls per turn;
  - 13 once-only score boxes;
  - live preview for unused boxes;
  - a longer scorecard deadline than quick poker, refreshed by valid scorecard state changes;
  - upper bonus at `63+`;
  - no joker rules and no extra five-of-a-kind bonus chains.
- The Shynok table-games hub shows the player's current gold, the Doppelganger availability paragraph and a separate `🪞 Допельґанґер` branch when he is in Shynok.
- The Doppelganger branch lets players choose `⚡ Швидкі кості`, `📜 Табличні кості` or `♟ Тавлеї`, then choose a stake.
- Tavlei against the Doppelganger uses the existing tavern-game escrow shape with one player stake: win returns the stake from escrow, draw refunds it, loss leaves it on the table, and replay/expiry/cancel paths settle once.
- Old incompatible active `kosti` sessions using the previous rules version are hidden from the hub and refunded through the existing safe refund path when old callbacks are pressed.
- Dice Poker uses the existing `TavernGameSession` / `TavernGameParticipant` escrow model without a Prisma schema change.
- Rewards stay bounded:
  - stake is reserved at session start;
  - quick win or high scorecard completion can pay back the stake from escrow;
  - draws/refunds/cancel/expiry return reserved stake only;
  - terminal sessions clear `activeStakeKey`;
  - duplicate completion callbacks do not pay again.
- Completed Dice Poker outcomes count in the existing tavern-games leaderboard from stored dice-poker result rows.
- Social Dice Poker stores each player's dice/scorecard state in `TavernGameParticipant.decisionJson`, settles the shared pot once all active players finish and records per-participant outcomes for the leaderboard.
- Social Dice Poker table starts are viewer-aware: quick and scorecard manual starts show each participant their own dice/card and controls, not a generic table card; quick also auto-starts after its short 2+ player join window or when the table fills to 8/8.
- Terminal social Dice Poker results notify other seated participants with the stored table result, active titles and rematch/back controls; scorecard result rows use readable blank-line blocks with bold names, scores and payouts; stale closed-table callbacks do not keep reroll/score buttons alive.
- The entry menu now asks for mode first and stake second, reducing the noisy stake grid on first open.
- Public table stake pickers use compact horizontal `👥` stake rows; Doppelganger stakes live in his separate branch.
- Rules opened from an active Dice Poker session can return to that current session.
- Quick result cards are spaced for readability, use combat-like win/loss/draw markers and show the exact stake payout/loss/refund amount.
- Open and ready Tavlei table cards separate title, table, bank and next action with blank lines, and show seated character names in bold with active cosmetic titles.
- Open Tavlei, quick-dice and scorecard-dice tables have creator-only invite controls: a shareable Telegram deep link plus a compact rotating invite card generated by the table creator.
- `/start game_...` deep-link joins notify already seated table participants like inline joins; quick Dice Poker sends seated players their own dice/card once the creator starts the 2-8 player table, it fills to capacity or the short 2+ player start window elapses, and Tavlei-ready joins send the creator the normal tactic-choice update.
- Active Dice Poker/Tavlei games against `🪞 Допельґанґер` count in `🎲 Ігри за столом` and `👀 Хто поруч` as occupied table games, but do not expose join buttons.
- Completed table-game result cards offer `🔁 Зіграти ще`: social games open a fresh same-stake table and privately invite previous opponents, while Doppelganger games start the same fallback path directly only while he is in Shynok; daytime presses show the existing blocked message and reserve no stake.
- Completed stored Dice Poker cards against `🪞 Допельґанґер` replay the terminal Dice Poker result and keep the direct repeat path instead of showing old Kosti stale-copy.
- `🏆 Рейтинг` includes `🪞 Допельґанґер` as a table-games opponent for completed Dice Poker/Tavlei fallback wins, draws and losses.
- New table creation no longer has a recent-create cooldown; the one-active-stake-session guard remains.
- The legacy local `/dev_reset_tavern_games` helper is now a no-op compatibility check because there is no table-create cooldown to reset; dev-only commands may reuse icons already used by other dev commands or player-facing commands.

## State and Compatibility Notes

- New Dice Poker sessions use `rulesVersion = dice-poker-v1` and `gameKey = kosti`.
- Tavlei vs Doppelganger sessions use `rulesVersion = tavlei-doppelganger-v1` and `gameKey = tavlei`.
- Legacy Kosti style/sign/join callbacks remain parseable only to fail closed through refund/stale paths; the new keyboards no longer emit those callbacks.
- Callback payloads are compact `v1:sh:gq*`, `gsm`, `gsc`, `gdm`, `gdo`, `gtn`, `gdt`, `gdr`, `gds`, `gdc`, `gpr`, `gdv` forms and stay under Telegram callback-data limits.
- At most one active stake session still applies through `activeStakeKey`.
- Quick Dice Poker uses a short social start window after the second player joins and a short action window after the table starts; unresolved quick social hands auto-finish as no-reroll hands instead of trapping other players. Scorecard Dice Poker uses the longer scorecard deadline and refreshes it on valid reroll/score/toggle saves.
- Dice Poker table expiry is handled before legacy Kosti resolution. Expired waiting/open single-player or scorecard `dice-poker-v1` rows refund through `dice_poker_expired`; replayed stale callbacks do not create old Kosti resolution rows or double-refund escrow.
- Expired unresolved Tavlei-vs-Doppelganger rows refund through `tavlei_doppelganger_expired`; stale replays do not choose a tactic or duplicate settlement.
- Invite-link join failures keep the retry path on the same still-open table: non-participants see `✅ Сісти за стіл`, while invite/share controls remain limited to the table creator.
- Invite-card view/rotate callbacks use a passive read path. If the join window or table status is stale, they return stale copy without expiring/refunding/resolving the table; actual join/action paths keep the existing safe settlement behavior.
- Scorecard no-op reroll callbacks with no selected dice do not consume a roll.
- `/dev_reset_tavern_games` is a local no-op compatibility helper after cooldown removal. It does not settle sessions, pay rewards, refund escrow or bypass replay-safety paths.

## Manual Telegram QA

Not run in this branch. Required manual checklist before release:

1. Open Shynok `🎲 Ігри за столом`, then `🎲 Кості`.
2. Verify the first Kosti card shows `⚡ Швидкі кості`, `📜 Табличні кості`, `❔ Правила` and no stake grid yet.
3. Verify `🎲 Ігри за столом` shows current gold, the Doppelganger paragraph and a separate `🪞 Допельґанґер` branch when he is in Shynok.
4. Choose a public Kosti mode, then verify the public-table stake picker appears as the second step with compact horizontal `👥` stake rows.
5. Start open Tavlei, `⚡ Швидкі кості` and `📜 Табличні кості` tables; on each creator waiting card press `📣 Запрошення до столу`, verify a compact invite card appears, press `🎲 Інший текст`, and verify the share URL button opens a Telegram share link.
6. From a seated non-creator account, verify invite buttons are absent and stale invite rotate callbacks answer that the creator manages invitations.
7. Open invite deep links from second and third accounts and verify they join the correct quick table without starting it immediately; press `▶️ Почати партію` as creator or wait for the short 2+ player start window, then verify every seated player receives their own dice/card and controls. For Tavlei-ready joins, verify the creator receives the tactic-choice update.
8. Press stale invite buttons after the table starts/closes or after the join window expires; verify a friendly stale answer, no stake is duplicated or removed incorrectly, no session status/gold mutation happens from invite preview, and no reroll/score controls remain on a closed table.
9. From a second account with insufficient gold, open an invite link, verify the response shows `✅ Сісти за стіл` rather than invite buttons, sell manatky for enough gold, press the same join button and verify the table join succeeds.
10. Start `⚡ Швидкі кості` as a social table; join from 2-8 accounts, start the table from the creator after at least two players are seated or wait for auto-start, verify every account sees its own dice/card, reroll none/some/all dice across attempts, finish all players and verify everyone receives the terminal result card.
11. Press `🔁 Зіграти ще` from the completed social result; verify the actor gets a fresh same-stake table and the previous opponent receives a private join invite.
12. Press duplicate `🔁 Зіграти ще` callbacks and verify they do not create duplicate tables or duplicate invites while the actor already has an active stake session.
13. At 23:00-07:00 Kyiv time, open `🪞 Допельґанґер`, choose quick dice, scorecard dice and Tavlei in separate attempts, then verify stake choice and one-time settlement.
14. Press `🔁 Зіграти ще` from a completed Doppelganger game during 23:00-07:00 and verify it starts the same fallback game directly without inviting a real player or showing old Kosti stale-copy.
15. Press `🔁 Зіграти ще` from a completed Doppelganger game outside 23:00-07:00 and verify the clear blocked message appears and no new stake is reserved.
16. Replay the completed Doppelganger result card and verify it still shows the Dice Poker result, not the legacy old-Kosti stale text.
17. Outside 23:00-07:00 Kyiv time, verify Shynok hides the `🪞 Допельґанґер` branch and stale direct fallback callbacks do not reserve a stake.
18. Open rules from an active game and return to that same game.
19. Start `📜 Табличні кості` as a social table with 2+ accounts; press `▶️ Почати партію`, verify each participant gets their own scorecard state, select dice, reroll twice, score boxes.
20. Finish all 13 turns or locally drive enough turns to verify terminal settlement; scorecard result rows should show bold names/titles, bold scores/payouts and blank lines between players.
21. Leave a scorecard open longer than the quick-poker window, continue it, then verify it still expires/refunds after the scorecard deadline.
22. Press stale old Kosti join/decision/resolve callbacks and verify friendly no-double-spend behavior.
23. Verify active games against `🪞 Допельґанґер` appear in `🎲 Ігри за столом` and `👀 Хто поруч` as occupied tables without join buttons.
24. Verify completed quick win/loss/draw, Tavlei-vs-Doppelganger outcome, high scorecard completion and `🪞 Допельґанґер`'s own win/draw/loss row appear in `🏆 Рейтинг`.
25. Cancel and expiry paths return escrow once, including an unstarted scorecard table whose join window expired and unresolved Tavlei vs Doppelganger.
26. Create a table, close or finish it, then immediately create another table and verify there is no recent-create cooldown blocker.
27. Verify open social Dice Poker table counts in `🎲 Ігри за столом` and join callbacks from another account.
28. Leave a started quick social table without all players acting; after the quick round window, verify unresolved hands finish as no-reroll hands, the shared pot settles once and stale callbacks do not keep players trapped.
