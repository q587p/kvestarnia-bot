# 0.2.32 - Combat and Korchma Polish Rollup

## Goal

Consolidate the small post-`0.2.31` fix PRs into one release branch and ship them as `0.2.32`.

## Scope

- Merge the open flee, Korchma hall hint, daily-round backlog and Yeger remort-pressure follow-ups into one PR.
- Move the Big Barrel reward correction notes out of the already-published `0.2.31` news/changelog block and into `0.2.32`.
- Keep already-merged `0.2.31` fixes as the base rather than re-stacking old branches.
- Bump package metadata and release surfaces to `0.2.32`.

## Shipped fixes

- Repeated persistent PvE flee attempts ramp from the old first-attempt chance to `93%` on attempt 5 and `100%` on attempt 7, using stored failed-flee turn logs.
- Korchma hall presence copy shows the "Yeger does not count" joke only once per character remort life through existing player hint receipts.
- Yeger contracts apply the existing combat-only remort-aware monster pressure from remort `3`, while ordinary one-enemy PvE keeps the previous threshold.
- Completed Big Barrel Brother result cards opened by non-participants show total raid rewards without assigning them to a specific participant.
- Big Barrel Brother victory settlement grants participant-specific Loot Expansion manatky instead of replaying the solo Barrel starter bundle for every participant.
- Solo Barrel raids grant the starter Barrel bundle only once per character completion ledger; later completions keep XP/gold and only sometimes grant a profile-based Loot Expansion manatka.
- `Корчмарський обхід` has a future-task note to expand small-catastrophe variants to `42` and reduce repeats for a character.

## Non-goals

- No schema or migration changes.
- No reward, loot/drop, Yeger progress or remort XP rebalance.
- No new combat actions, markets, crafting, shops or broad quest redesign.
