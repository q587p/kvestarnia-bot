# 0.1.13 — Problem Fight Difficulty Choice

## Goal

Give players a compact risk/reward choice before an ordinary persistent problem fight starts, so repeated losses do not trap them behind only full-strength encounters.

## Scope

- Route `/fight`, Quest Hub `Розвʼязати проблему`, and post-fight `Новий бій` through a difficulty choice when no active persistent fight exists.
- Add typed quest callback data for easier, ordinary, and harder problem fights.
- Make level selection deterministic and testable:
  - easier: about character level minus 3, clamped to a safe minimum;
  - ordinary: current monster selection behavior;
  - harder: about character level plus 2.
- Store the selected intervention in combat state so turn resolution and reward recovery keep using the selected effective monster level.
- Scale XP, gold, and drop opportunity conservatively through the existing solo combat reward path.

## Non-goals

- No shops, selling, crafting, trading, markets, migrations, or broad economy systems.
- No changes to problem quest counters, pending-raid protection, level gates, cooldowns, combat action rules, or reward idempotency.
- No changes to doppelganger training or duel reward rules.

## Acceptance Criteria

- Clicking `Розвʼязати проблему` does not immediately create a level 3+ persistent fight when no active fight exists.
- Active sessions still open the current fight screen, including stale/duplicate callback safety.
- Difficulty callbacks start or resume the existing persistent fight session path.
- Terminal/replayed rewards remain idempotent and use the stored difficulty/effective level.
- Player-facing text is short, Ukrainian, and HTML-safe.

## Focused Tests

- Quest callback parsing and Telegram callback length.
- Difficulty keyboard/presenter rendering.
- Quest Hub path does not surprise-start combat.
- Easy/ordinary/hard monster level selection.
- Conservative reward scaling and replay.
- Active-session and stale/invalid callback safety.

## Manual Telegram QA

- Level 3+ character with an issued problem opens `/fight` and sees difficulty choices.
- Quest Hub `Розвʼязати проблему` shows the same choice.
- Each difficulty starts a fight and the active fight buttons continue working.
- After win/loss/flee, `Новий бій` returns to difficulty choice.
