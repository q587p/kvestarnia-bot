# 0.1.11 — Duel Rematch and Shareable Result Cards

## Goal

Make resolved duel cards more useful without turning the first duel ledger into farmable PvP.

## Scope

- Add result-card buttons for a rewardless rematch and a shareable saved result card.
- Rematches create a new targeted duel challenge between the original participants only.
- Shareable cards send a separate forwardable message that reuses the stored result and never rerolls the duel.
- Limit one character pair to three resolved duel results per hourly `xx:23` reset window, including rematches and ordinary accepted invites.
- Keep fresh duel and rematch invites open for 13 minutes.
- Keep all duel flows level 3+, opt-in, replay-safe and rewardless.
- Fix the remort reset papercut that could leave starter/problem-chain daily action rows attached to the new life.
- Add a dry-run-first maintenance cleanup for production characters already affected before the fix deploy.

## Acceptance

- Resolved duel cards expose `Реванш` and `Картка`.
- Only original duel participants can create a rematch from a saved result.
- Only the targeted opponent can accept a targeted rematch; bystanders cannot hijack it.
- Partial HP/mana still shows an explicit warning before creating a rematch.
- Share callbacks send a result card as a new message and do not mutate duel state.
- A fourth duel between the same pair in the current `xx:23` window is blocked with a game-style suggestion to invite someone else.
- Remort confirm clears the per-life starter/problem-chain daily action keys that must reset after a new life.
- Production cleanup can remove stale matching `daily_actions` rows created before a character's latest remort without touching new-life rows created after that remort.

## Tests

- Callback parser coverage for rematch/share actions.
- Service coverage for targeted rematch creation, resource warning and target-only accept.
- Service coverage for same-pair duel limits, reset windows and rematch blocking.
- Bot callback coverage for resolved result keyboards, rematch creation, share cards and not-target accepts.
- Bot callback coverage for the same-pair limit message and fallback keyboard.
- Remort service coverage for reset daily action keys.
