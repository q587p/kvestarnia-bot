# 0.2.22 - Dense Bandage And Field Kit

Status: shipped in `0.2.22`.

## Goal

Add two craftable medical items made from the existing ordinary bandage:

- `Щільний бинт`
- `Польова аптечка`

Crafting starts from the ordinary bandage item detail card, works only outside combat, and reuses the current item, inventory, callback and combat-state architecture.

Advanced supply visibility and backend access require the second Yeger board to be completed: `YEGER_UNQUIET_TRIAL_SECOND_TARGET = 17` unquiet wins turned in. Before that completion, craft callbacks fail closed without spending bandages or granting crafted items.

## Scope

- Preserve the existing ordinary bandage effect and supply rules.
- Add recipe-shaped configuration for both crafts.
- Show craft buttons on the ordinary bandage card only outside combat, only after second-board completion, and only with enough ordinary bandages:
  - `Створити щільний бинт` at `8+`
  - `Створити польову аптечку` at `13+`
- Recheck inventory count, active combat absence and second-board completion on backend preview/confirm callbacks.
- On successful craft, atomically subtract ordinary bandages and add exactly one crafted item.
- Let successful Ranger/Yeger craft rolls save `1-5` ordinary bandages based on character level/luck, while still requiring the full recipe stack before the craft starts; other classes spend the fixed recipe cost.
- After a successful craft, offer `Створити ще` when the remaining ordinary bandage count can pay the same recipe again.
- Add solo-combat and Big Barrel raid item support for the crafted items.
- Upgrade Ranger/Yeger class supplies: after the first board the free 93-minute claim grants `5` ordinary bandages; after the second board Rangers can also claim `1` dense bandage every `93` minutes and `1` field kit every `24` hours.
- Let party-boss / Big Barrel item use accept the same combat-usable medical manatky as solo combat.
- Add a `Разові` button to `Манатки` that filters one-use consumables through the same inventory filter and pagination path as equipment-slot filters.
- Keep inventory list message bodies compact by omitting per-item descriptions there; item detail buttons show stack counts in parentheses when quantity is greater than one.
- Keep the Yeger corner atmosphere separate from Yeger quest-detail cards, with quest-card back buttons returning to the Yeger corner and ordinary Yeger exits returning to the Barrel.
- Suppress duplicate Yeger corner movement notices when the Yeger card or a Yeger daily scene is already being shown.
- After the second Yeger board turn-in, show dense-bandage and field-kit craft shortcuts when the remaining ordinary bandage stack can pay the recipes.
- Keep full-HP medical item no-op cards honest and route them back to the source bandage/kit detail card.

## Item Rules

`Щільний бинт`:

- Craft cost: `8` ordinary bandages -> `1` dense bandage.
- Use effect: restore up to `42 HP`, capped by max HP.
- Full-HP no-op: no consume and no cooldown.
- Combat rule: after successful use, `5` own-turn cooldown scoped to the current battle.

`Польова аптечка`:

- Craft cost: `13` ordinary bandages -> `1` field kit.
- Use effect: raise current HP to at least `ceil(maxHp * 93 / 100)`.
- Integer examples: `50 -> 47`, `100 -> 93`, `200 -> 186`.
- No-op at or above the target HP: no consume and no limit spend.
- Combat rule: `1` successful use per battle.

## Non-goals

- No broad crafting system, shops, trading, economy rebalance or item-instance inventory redesign.
- No rare extra components.
- No XP, gold, title, combat power, unlock gate or hidden reward for crafting or using these items; the slice adds only rewardless achievement records for first craft/use moments.
- No changes to ordinary bandage healing or paid Yeger bandage purchase rules.
- No broad raid item system beyond combat-usable medical manatky; targetable manatky and fuller raid item roles remain deferred.
- No Prisma schema or migration.

## Acceptance Criteria

- Ordinary bandage item cards show craft buttons only after second-board completion, outside combat and with enough ordinary bandages.
- Direct/stale advanced craft callbacks before unlock, during combat or below the required count fail safely without mutation.
- Exact-count craft works for `8` and `13` ordinary bandages.
- Ranger/Yeger craft savings can preserve ordinary bandages after a successful roll without bypassing the recipe's up-front stack requirement; non-ranger classes do not receive savings.
- Successful craft result cards show `Створити ще` only when the remaining ordinary bandage stack still covers the same recipe.
- Crafted item use is replay-safe and does not consume on no-op.
- Dense bandage healing is capped at max HP and sets cooldown only after successful healing.
- Field kit target HP uses `ceil(maxHp * 93 / 100)` and spends its combat limit only after successful healing.
- Dense cooldown and field-kit limit are scoped to the current battle.
- Existing ordinary bandage behavior remains unchanged.
- Ranger supplies are locked until the matching Yeger board completion, use independent cooldown keys and can feed the same solo-combat / Big Barrel medical item-use path after the items are owned.
- Successful craft, solo-combat use and Big Barrel medical item use can unlock their matching rewardless achievement once without changing rewards or combat power.
- `Манатки` exposes a `Разові` filter that lists ordinary, dense and field-kit medical consumables without showing equipment or junk stacks, and item detail back buttons return to that filtered list.
- Inventory list text stays to the heading, value/count and pagination lines; item names remain available through buttons, with `(N)` shown only for stacks above one.
- Yeger entry routes show a single Yeger card or daily scene without a preceding duplicate `Ви підійшли до єгерського кутка.` movement notice.
- Completing or replaying the second Yeger board turn-in offers `Створити щільний бинт` / `Створити польову аптечку` shortcuts only when the ordinary bandage stack is sufficient.

## Achievement Decision

- Adds rewardless achievements for first `Щільний бинт` craft, first `Польова аптечка` craft, first successful combat use of each crafted item and first medical item use in the Big Barrel raid.
- Craft achievements unlock at the successful craft boundary. This slice does not add a crafting ledger or Prisma migration, so long-term craft counters remain out of scope.
- Item-use achievements rely on existing solo-combat item logs and Big Barrel action rows for durable recalculation where those rows exist.
- Improved Ranger supplies reuse the existing rewardless first free-supply achievement event; no separate dense/field-kit class-supply achievements are added because the new durable/visible achievement coverage is already on craft, use and Big Barrel medical item use, without adding power rewards.
