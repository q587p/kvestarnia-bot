# 0.1.19 — Nyz Passage Balance Polish

Status: Implemented
Type: Versioned implementation task

## Goal

Retune the three `Ярус I: Сутерени Корчми` passage choices so playtest rewards match the promised risk shape: the easy right passage is clearly easier and pays less, the straight passage remains the baseline, and the hard left passage pays more than the baseline without overpaying.

## Scope

- Update only the ordinary/problem fight passage balance around `Підсходник` and `Ярус I: Сутерени Корчми`.
- Change the right/easy passage from the current small level adjustment to prefer available monsters `3-5` levels below the character, with safe fallback/clamping when content is missing.
- Keep the straight/center passage as the unchanged baseline for monster level, XP and broad loot profile; gold uses the shared variable roll.
- Keep the left/hard passage harder than the center passage and ensure its completed-fight XP remains higher than the center route for the same base monster.
- Reduce the current side-passage reward pressure where needed: right must pay meaningfully less XP than center, left may be toned down from any excessive bonus but must stay above center for XP.
- Make side-passage XP range-based: easy/right rolls `0.5x-0.75x` character level with a small LUCK bias toward the top of the range; hard/left rolls `1.25x-1.5x` character level with the same bounded LUCK bias.
- Make fight gold variable from `0` to current character level instead of stable by monster level across ordinary, Yeger and adventure persistent-fight sources.
- Keep non-combat turn-in gold/item rewards out of the variable-gold path; soften the first Yeger quest XP turn-in with a level-scaled cap so early characters cannot jump two levels from the final claim alone.
- When gold rolls `0`, raise the item drop chance to `93%`, then interpolate back down to the difficulty-adjusted configured drop chance at the max-gold edge while keeping the existing loot item/rarity pipeline.
- Restore the previous side-passage loot modifiers: easy/right uses `0.65` drop chance multiplier and `-1` loot power offset; center uses `1` and `0`; hard/left uses `1.35` and `+1`.
- If XP reward math produces fractions, round the easy/right passage down.
- Preserve stored reward replay/idempotency: an already completed fight keeps its original stored result.
- Keep pre-choice copy qualitative; do not print exact future XP, gold, item names, odds or formulas before commitment.

## Non-goals

- No duel, training, nearby invite, trading, tournament, wager or rating changes.
- No broad XP curve, loot-table or economy rewrite.
- No new monsters, locations, migrations or schema changes unless the existing code path unexpectedly requires a narrow compatibility fix.
- No change to the same-location policy or combat-lock behavior.
- No change to monster-rest eligibility/timer behavior except if a direct regression test needs updated expectations for passage balance.

## Acceptance criteria

- Right/easy passage starts a fight with an available monster `3-5` levels below the character when the pool has one, with safe fallback/clamping for low-level or missing content.
- Center passage keeps the current baseline monster and XP behavior; gold uses the shared variable roll.
- Left/hard passage is harder than center and pays more XP than the center route for the same base monster after victory; its minimum uses the center baseline plus one, not the hard effective monster level.
- Right/easy passage pays less XP than center after victory; fractional XP reward rounding goes downward for the easy passage.
- Gold is no longer deterministically ordered by passage and can roll from `0` to current character level for normal, Yeger and adventure persistent-fight wins; quest turn-ins do not use this variable-gold roll.
- The first Yeger quest turn-in keeps fixed gold/item rewards but scales XP by level with a cap at the old high-level value, while old completed rows replay their stored XP.
- `0` gold strongly favors a manatka drop, while max gold keeps the current difficulty-adjusted configured item drop chance.
- Replay of old completed fight results does not recompute XP, gold or broad loot profile.
- Player-facing passage choice copy stays qualitative and mobile-sized.
- Existing `Низ`, `Спуск до Низу`, `Ярус I: Сутерени Корчми` and `Підсходник` terminology remains intact.
- Relevant automated tests pass or blockers are named.

## Focused tests

- Passage effective-level tests for right/center/left, including right-passage `3-5` lower selection and low-level fallback/clamp.
- Fight service reward tests proving XP ordering for comparable wins: `left > center > right`.
- Hard floor tests proving the left passage floors from the center baseline for the same base monster, and that high-level hard rolls can still exceed that floor.
- Easy/right rounding-down test for fractional XP reward math.
- Variable gold reward tests proving normal, Yeger and adventure persistent-fight gold can vary within `0..character level`, plus zero-gold item-drop boost and threshold-boundary cases.
- Yeger turn-in coverage proving low-level XP is capped, old stored XP replays, and gold/item rewards remain fixed.
- Adventure turn-in coverage proving fixed non-combat quest rewards are unaffected.
- Replay/idempotency test proving stored completed results are not recomputed.
- Presenter or callback HTML tests proving no exact future rewards are shown before passage selection.
- Run `npm run check` before PR handoff.

## Manual Telegram QA

- Preconditions: create a level 3+ character with access to ordinary/problem fights through `Спуск до Низу`.
- User action: enter `Ярус I: Сутерени Корчми`, run comparable wins through right, center and left passages.
- Expected bot response: right feels safer and pays less XP; center remains the normal baseline; left is harder and pays more XP; gold varies instead of staying fixed by passage, and zero-gold wins should still feel capable of paying through manatky.
- Expected state: completed fight rewards are stored once and replayed without recomputation.
