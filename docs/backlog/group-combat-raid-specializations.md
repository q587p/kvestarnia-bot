# GroupCombat raid-specialization review

Status: scheduled after the accepted `0.4.8`–`0.4.15` sequence; no implementation
version is assigned until ordinary weekly-guild participation is measured.

This backlog item owns the four Big Barrel-only specialization decisions below.
It must either define genuinely equivalent multi-enemy semantics or preserve the
raid-only boundary. Approximate copies are not acceptable.

## warrior-raid-taunt

Decide whether a multi-enemy analogue can coexist with resolved-turn GroupCombat
focus without replacing the generic Warrior class profile.

## bard-lament

Decide whether GroupCombat should ever own a party-wide music slot and a response
clock distinct from ordinary timed effects.

## kharakternyk-ward-sign

Decide whether a recruitment-time, broad-response-only support ritual has a
non-boss meaning. Preserve the ordinary race action independently.

## bureaucramancer-protocol-13-z

Decide whether pre-combat signatures and one-response blocks belong outside a
single-boss raid. Preserve `skill.form-thirteen-b` as the ordinary class action.
