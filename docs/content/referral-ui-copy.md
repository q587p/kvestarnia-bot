# Українські тексти — Поклик до Квестарні

Канон: [`0.4.6 Referral Foundation`](../tasks/0.4.6-referral-foundation.md).

Усі динамічні імена проходять referral-specific sanitization і фінальне HTML escaping. У тексти й журнали не потрапляють Telegram username/ID, guild crest/name/custom emoji, destination chat або raw token; токен дозволений лише всередині контрольованого deep/share URL, який бот показує власникові поклику.

## Назви й кнопки

- Поверхня: `📨 Поклик до Квестарні`
- Список: `👥 Мої покликані`
- Generate: `📝 Згенерувати запрошення`
- Regenerate: `🎲 Перегенерувати текст`
- Share: `📨 Поділитися запрошенням`
- Accept: `✅ Прийняти поклик`
- Decline without blocking onboarding: `Продовжити без поклику`
- Refresh: `🔄 Оновити`
- Back: `↩️ До Дошки`
- Pagination: `⬅️` / `➡️`

Не використовувати player-facing `claim`, `entitlement`, `receipt`, `referral ID`, `qualified` або `retained`.

## Дошка корчми

```html
📨 <b>Поклик до Квестарні</b>

Поклич нового пригодника. Коли той набиратиметься досвіду, Квестарня автоматично видаватиме тобі припаси, Іскрокамені та золото.
```

Кнопка: `📨 Відкрити поклик`.

## Головний екран

```html
📨 <b>Поклик до Квестарні</b>

Поклич нового пригодника. За чотири ранні рівневі звитяги Квестарня автоматично видаватиме тобі ці нагороди:

3 рівень — 🩹 Щільний бинт ×1 · ✨ 5 Іскрокаменів · 💰 50 золота
5 рівень — ⚕️ Польова аптечка ×1 · ✨ 13 Іскрокаменів · 💰 120 золота
8 рівень — ⚕️ Польова аптечка ×2 · ✨ 65 Іскрокаменів · 💰 760 золота
13 рівень — ⚕️ Польова аптечка ×3 · ✨ 193 Іскрокамені · 💰 900 золота

🔗 <b>Твоє посилання:</b>
https://t.me/BOT_USERNAME?start=ref1_TOKEN

👥 Покликано й прибуло: <b>2</b>
🎁 Виплачено етапів: <b>4</b>
Досягнуті етапи: 3 — 2/2 · 5 — 1/2 · 8 — 1/2 · 13 — 0/2
```

Ця точна таблиця до поширення — вузький owner-approved виняток лише для приватного dashboard запрошувача. Consent card, lore і `news.md` не повторюють її.

Keyboard:

```text
📝 Згенерувати запрошення
👥 Мої покликані
🔄 Оновити
↩️ До Дошки
```

Немає кнопки `Забрати нагороду`.

### Генератор тексту запрошення

Окремий екран показує один із 13 різних коротких українських текстів із безпечним імʼям запрошувача. Кнопка `🎲 Перегенерувати текст` переходить до наступного варіянта, а стабільне referral-посилання при цьому не змінюється.

```text
📨 Поділитися запрошенням
🎲 Перегенерувати текст
🔗 Скопіювати посилання
↩️ До поклику
```

Усі 13 текстів мають бути досяжні послідовними натисканнями; callback не містить referral-токена.

### Є pending-виплати

Додати після stage line:

```html
⏳ Автоматичної доставки чекає: <b>1</b>.
Нічого натискати не треба — Квестарня повторить виплату сама.
```

### Немає чинного персонажа

Якщо link ще ніколи не створювали:

```html
📨 <b>Поклик до Квестарні</b>

Спершу створи пригодника. Тоді Корчмар матиме кому виписати посилання й кому складати майбутні нагороди.
```

Кнопка: `🪶 Створити персонажа`.

Якщо User уже мав stable link:

```html
📨 <b>Поклик до Квестарні</b>

Твій поклик досі чинний і не змінився після перезапуску.

🔗 https://t.me/BOT_USERNAME?start=ref1_TOKEN

Нагороди, які вже чекають автоматичної доставки, не зникнуть. Коли зʼявиться чинний персонаж і доставка буде доступна, Квестарня повторить спробу. Забирати вручну нічого не треба.
```

Keyboard:

```text
📝 Згенерувати запрошення
🪶 Створити персонажа
```

### Функція вимкнена

```html
Писар тимчасово не приймає нових покликів. Уже записані пригодники й зароблені етапи не зникнуть.
```

## Forwardable share draft

```html
📨 <b>Поклик до Квестарні</b>

«ІМʼЯ ПЕРСОНАЖА» лишає тобі поклик до Квестарні. Створи пригодника — корчма вже сперечається, який кухоль вважати вітальним.
```

Це перший із 13 канонічних варіянтів. Кнопка `📨 Поділитися запрошенням` використовує Telegram Share URL і окремо передає стабільне referral-посилання. Гравець сам обирає чат/групу/канал і може змінити текст. Бот не зберігає destination.

## Landing і consent

```html
🤝 <b>Поклик від «ІМʼЯ ПЕРСОНАЖА»</b>

Можеш прийняти цей поклик або продовжити самостійно — створення пригодника доступне в обох випадках.

Якщо приймеш, запрошувач автоматично отримає припаси, Іскрокамені та золото, коли ти вперше досягнеш 3, 5, 8 і 13 рівня.

Запрошувач бачитиме лише імʼя твого чинного пригодника, поточний рівень і позначки цих чотирьох етапів. Telegram-профіль, місце, справи, речі, золото та ґільдія лишаться приватними.

Після створення пригодника Хроніки Квестарні публічно запишуть імʼя нового пригодника, імʼя запрошувача й сам факт поклику в розділі «Пригодники». Посилання, Telegram-дані, рівні та нагороди туди не потраплять.

Вибір одноразовий: якщо продовжиш без поклику, інше посилання пізніше не привʼяже цей облік до запрошувача.
```

Keyboard:

```text
✅ Прийняти поклик
Продовжити без поклику
```

### Invitee accepted

```html
🤝 Поклик прийнято.

Квестарня запамʼятала, хто кого сюди привів. Тепер час створити пригодника.

Після створення персонажа Хроніки запишуть обидва імена та факт поклику в розділі «Пригодники».
```

Продовжити canonical onboarding без окремого reward screen.

### Continued without referral

```html
Гаразд. Поклик не прийнято. Запрошувач тебе не побачить і нагород не отримає; інше посилання вже не змінить цього вибору.

Звичайне створення пригодника триває.
```

## Inviter join notification

```html
🤝 <b>Новий поклик прийнято!</b>

У журналі зʼявилося імʼя: <b>«Книжкова Оркиня»</b>.

Нагороди прийдуть автоматично:
3 рівень — 🩹 Щільний бинт ×1 · ✨ 5 Іскрокаменів · 💰 50 золота
5 рівень — ⚕️ Польова аптечка ×1 · ✨ 13 Іскрокаменів · 💰 120 золота
8 рівень — ⚕️ Польова аптечка ×2 · ✨ 65 Іскрокаменів · 💰 760 золота
13 рівень — ⚕️ Польова аптечка ×3 · ✨ 193 Іскрокамені · 💰 900 золота

Уся шкала дає золото на базові кроки від +1 до +5, а останній етап — каміння навіть на найдорожчу чинну спробу з +4 до +5. Не на +6.
```

Лише після committed `ACCEPTED` **і** першого створення Character з безпечним імʼям. Не надсилати, якщо сталася лише одна з цих подій, а також за link open, pending capture чи decline.

## Automatic payout notifications

Лише після committed item-and-gold bundle + `GRANTED` receipt. У pending-стані повідомлення `нараховано` заборонене.

### Level 3

```html
🎁 <b>Нагорода за поклик!</b>

🎉 Етап пригодника <b>«Книжкова Оркиня»</b>: <b>3 рівень</b>.
Тобі автоматично видано: 🩹 Щільний бинт ×1, ✨ 5 Іскрокаменів і 💰 50 золота.
```

### Level 5

```html
🎁 <b>Нагорода за поклик!</b>

🎉 Етап пригодника <b>«Книжкова Оркиня»</b>: <b>5 рівень</b>.
Тобі автоматично видано: ⚕️ Польова аптечка ×1, ✨ 13 Іскрокаменів і 💰 120 золота.
```

### Level 8

```html
🎁 <b>Нагорода за поклик!</b>

🎉 Етап пригодника <b>«Книжкова Оркиня»</b>: <b>8 рівень</b>.
Тобі автоматично видано: ⚕️ Польова аптечка ×2, ✨ 65 Іскрокаменів і 💰 760 золота.
```

### Level 13

```html
🎁 <b>Нагорода за поклик!</b>

🎉 Етап пригодника <b>«Книжкова Оркиня»</b>: <b>13 рівень</b>.
Тобі автоматично видано: ⚕️ Польова аптечка ×3, ✨ 193 Іскрокамені й 💰 900 золота.

193 Іскрокамені останнього етапу покривають найдорожчу чинну спробу покращення з +4 до +5: для легендарного предмета потрібно 180. Загальне золото чотирьох етапів покриває базові кроки від +1 до +5. Це не відкриває та не обіцяє +6.
```

Не намагатися граматично відмінювати довільне Character name автоматично. Production presenter використовує цю нейтральну конструкцію:

```html
🎉 Етап пригодника <b>«ІМʼЯ»</b>: <b>8 рівень</b>.
Тобі автоматично видано: ⚕️ Польова аптечка ×2, ✨ 65 Іскрокаменів і 💰 760 золота.
```

`Книжкова Оркиня` вище лише показує бажаний ритм прикладу; будь-яке імʼя підставляється без відмінювання.

### Invitee зараз без Character

Якщо automatic payout відбувається після restart invitee й чинного імені немає, не затримувати нагороду й не відновлювати старе імʼя:

```html
🎁 <b>Нагорода за поклик!</b>

🎉 Етап покликаного пригодника: <b>8 рівень</b>.
Тобі автоматично видано: ⚕️ Польова аптечка ×2, ✨ 65 Іскрокаменів і 💰 760 золота.
```

Це параметризований fallback для всіх чотирьох stages: level, усі item grants та gold беруться з frozen reward bundle. Він не створює нового name snapshot. Для 13 рівня після bundle presenter додає той самий точний абзац про найдорожчу чинну спробу `+4 → +5`, повну базову золоту драбину й відсутність `+6`, що й у named template.

## Хроніки Квестарні

Лише після явної згоди та підтвердженого створення першого персонажа. Цей рядок замінює звичайний `character.created` для цього персонажа, а не дублює його:

```html
🤝 12:34 | Новий пригодник у Квестарні: «Книжкова Оркиня», за покликом «Zhe Baykov».
```

Подія має normal severity й показується в `Усі` та `👥 Пригодники`, але не в `⭐ Важливе` чи `🎒 Манатки`. Обидва іменні snapshot-и зберігаються як окремо очищений plain text, а під час показу кожен екранується рівно один раз. Не показувати Telegram-дані, raw token, посилання, ґільдію, місце, рівень, нагороду, золото чи інвентар. Replay/restart не створює другого рядка й не змінює первісний час.

## Мої покликані

```html
👥 <b>Мої покликані</b>

Усього: <b>2</b> · Сторінка 1/1

1. <b>«Zhe Baykov»</b> · 11 рівень
   3:✅ · 5:✅ · 8:✅ · 13:▫️
2. <b>«Книжкова Оркиня»</b> · 4 рівень
   3:✅ · 5:▫️ · 8:▫️ · 13:▫️
```

Legend only when a pending row is present:

```html
✅ виплачено · ⏳ досягнуто, доставка в черзі · ▫️ ще попереду
```

A pending stage uses `⏳`; a granted stage uses `✅`. Historical state comes from durable reward rows, not current level.

### Invitee restarted and has no Character

```html
3. <b>Покликаний пригодник</b> · зараз без чинного персонажа
   3:✅ · 5:✅ · 8:▫️ · 13:▫️
```

Never erase earned checks or infer that they are invalid because current level is lower.

### Empty list

```html
👥 <b>Мої покликані</b>

Поки ніхто не прийняв твій поклик і не створив пригодника.
Посилання можна надіслати приватно або опублікувати там, де його справді чекають.
```

## Rejection and recovery copy

### Existing User

```html
Цей поклик призначений для нового гравця. Твої нинішні пригоди й звʼязки не змінено.
```

### Self-referral

```html
Корчмар звірив підписи. Покликати до Квестарні самого себе цим папірцем не вийде.
```

### Pending, opened another link

```html
Перший поклик уже чекає твого рішення. Інше посилання його не замінить.
```

Кнопка: `↩️ До першого поклику` — відкрити consent із canonical attribution, без raw token у callback.

### Already accepted, opened another link

```html
Поклик уже прийнято. Інше посилання не змінює запису в журналі.
```

### Already declined, opened another link

```html
Поклик уже було відхилено. Інше посилання не привʼяже цей облік до запрошувача.
```

### Invalid or unknown link

```html
Печатка на поклику пошкоджена або невідома Квестарні. Звичайний вхід усе одно відкритий.
```

### Foundation disabled during landing

```html
Нові поклики тимчасово не записують. Можна продовжити звичайне створення пригодника.
```

Показати `Продовжити без поклику`; ця дія остаточно закриває pending-поклик і лише тоді продовжує onboarding.

### Stale/wrong-owner callback

Alert:

```text
Цей запис уже змінився. Онови сторінку.
```

### Payout failure visible to inviter

Do not expose an error stack or ask for manual claim. Dashboard line:

```html
⏳ Одна нагорода вже зароблена й чекає автоматичної доставки.
```

## Copy invariants

- Exact bundles are always `3→dense×1 + iskro×5 + gold50`, `5→kit×1 + iskro×13 + gold120`, `8→kit×2 + iskro×65 + gold760`, `13→kit×3 + iskro×193 + gold900`.
- The dashboard uses canonical Ukrainian item names and never exposes technical `item.*` identifiers.
- The dashboard does not render a separate aggregate `Разом — …` reward line; economic totals remain policy/test evidence only.
- The stable referral URL has 13 distinct reachable share-copy variants; regenerating copy never rotates the token.
- The level-13 explanation says `193` covers the most expensive current single `+4 → +5` attempt, not the preceding steps; it never says or implies `+6`.
- Use `автоматично` in the join notice and reward contract.
- Use `видано/отримано` only after committed grant.
- No promise of a reward for the invitee merely joining.
- No hidden time or activity condition in prose.
- No claim button.
- No guild icon/name in any referral identity.
- No technical explanation of alt farming in player copy.
