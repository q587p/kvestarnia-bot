# Старий жертовник — player-facing copy seeds

Use Ukrainian player-facing copy. Keep it short for Telegram cards.

## Yard card additions

### Option A — light

```text
🪣 Задвірок корчми

За корчмою пахне мокрим деревом, самовпевненим пилом і дрібними проблемами, які не пройшли через головні двері.

Біля старого кореня темніє камінь. Корчмар каже, що це просто жертовник. Жертовник мовчить так, ніби вже записав вашу позицію.

Що робимо?
```

### Option B — more mysterious

```text
🪣 Задвірок корчми

За дровами починається тиша, яку Корчма не ставила в меню. Між корінням лежить старий жертовник: камінь без написів, але з дуже уважним виглядом.

Якщо сьогоднішній Корчмарський обхід прислав вас сюди, дрібницю треба владнати саме тут. Якщо ні, задвірок чемно вдає пейзаж.

Що робимо?
```

### Option C — more comedic

```text
🪣 Задвірок корчми

За корчмою сушаться відра, дрова й одна давня таємниця, яку ніхто не забрав із минулого тижня.

Під корінням стоїть старий жертовник. Корчмар називає його «камінь для зайвого пафосу», але пил на ньому лежить занадто урочисто.

Що робимо?
```

## Altar open card

### Default

```text
🪨 Старий жертовник

Старий камінь лежить між корінням і вдає, що не слухає. На ньому темніють зарубки: хтось просив сили, хтось — вдачі, хтось — щоб Корчмар не питав, звідки ця манатка.

Благовоління: <b>{favor}</b>.

Тут можна принести требу. Жрець може провести обряд і попросити коротке благословення для себе або когось активного поруч.
```

### No character

```text
🪨 <b>Старий жертовник не знає, кого записувати</b>

Спершу створіть пригодника через /start. Камінь любить імена, навіть якщо робить вигляд, що ні.
```

### Actor blocked

```text
🪨 <b>Жертовник чекає</b>

Обряд недоступний під час бою або рейду. Камінь уже бачив поспіх і досі не пробачив йому граматику.

Завершіть поточну справу й оновіть картку.
```

## Altar help card

```text
📜 <b>Як працює Старий жертовник</b>

Треба — це дар. Благовоління — це слід, який дар лишає на камені.

• Принесіть требу, щоб отримати Благовоління.
• Жрець витрачає Благовоління й ману, щоб провести обряд.
• Благословення діє недовго й видно в персонажі.
• Одне благословення не складається з іншим.

Корчмар каже, що це не торгівля. Жертовник теж так каже, але без слів.
```

## Gold offering flow

### Offer options

```text
🎁 <b>Принести требу</b>

Жертовник приймає прості дари. У відповідь він лишає Благовоління — не обіцянку, а радше уважну позначку на камені.

Сьогодні з дарів золотом отримано: <b>{favorToday}/{dailyCap}</b> Благовоління.

Що кладемо?
```

Button:

```text
🪙 13 золота → 1 Благовоління
```

### Confirm gold offering

```text
🎁 <b>Підтвердити требу</b>

Ви покладете на жертовник <b>13</b> золота.

Отримаєте: <b>1 Благовоління</b>.

Золото зникне чесно, урочисто й без повернення.
```

Buttons:

```text
✅ Принести требу
⬅️ Назад
```

### Completed gold offering

```text
🎁 <b>Требу прийнято</b>

Золото тихо лягло на камінь і стало частиною місцевої бухгалтерії тиші.

Отримано: <b>+1 Благовоління</b>.
Благовоління тепер: <b>{favor}</b>.
```

### Not enough gold

```text
🪙 <b>Золото не склалося в требу</b>

Потрібно: <b>13</b> золота.
У вас: <b>{gold}</b>.

Жертовник не сердиться. Він просто виглядає як камінь, який умів чекати ще до появи черги.
```

### Daily cap reached

```text
🎁 <b>Сьогодні камінь уже наслухався золота</b>

З дарів золотом сьогодні вже отримано максимум Благовоління: <b>{dailyCap}/{dailyCap}</b>.

Поверніться завтра за київським часом або попросіть Жреця використати те, що вже є.
```


## Blocked blessing states

### Not Priest

```text
✨ <b>Обряд потребує Жреця</b>

Принести требу може кожен. А от перетворити Благовоління на благословення — робота Жреця.
```

### Not enough favor

```text
🪨 <b>Благовоління замало</b>

Потрібно: <b>{required}</b>.
Є: <b>{favor}</b>.

Можна принести требу або обрати слабший обряд.
```

### Not enough mana

```text
💫 <b>Мани замало</b>

Потрібно: <b>{required}</b>.
Є: <b>{mana}</b>.

Жертовник поважає драму, але не проводить обряди в кредит.
```

### Already blessed

```text
✨ <b>Благословення вже тримається</b>

На цілі вже є активне благословення. Старий жертовник не складає урочистість у стопку.
```

### Same target wait

```text
✨ <b>Камінь памʼятає цей обряд</b>

Цю ціль ви вже благословляли нещодавно. Повтор можна буде зробити за <b>{remaining}</b>.
```

### Stale target/location

```text
📍 <b>Ціль уже не біля жертовника</b>

Хтось рушив далі, а старий камінь не бігає за людьми. Оновіть картку й оберіть доступну ціль.
```
