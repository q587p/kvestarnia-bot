# Public Site and Copy Audit Checklist

## Site

- Homepage hero uses current positioning.
- Latest news is newer than `0.0.24` if repository `news.md` is newer.
- `/news` archive lists current `0.2.x` entries or clearly documents limitation.
- `Що вже можна спробувати` matches README current playable list.
- Presence text remains privacy-safe.

## Telegram

- Bot description does not promise guilds/raids/market/crafting as playable.
- Channel links are correct.
- Bot username and project name follow Brand.

## Repo docs

- README remains public-facing, not dev runbook.
- Product Brief support wording matches Brand: `Банка підтримки Квестарні`.
- Roadmap and Deferred docs agree on next order.
- Task index marks drafts vs active tasks clearly.

## Tone

- Ukrainian-first, not localization.
- Short, funny, warm, not humiliating.
- Future features framed as roadmap.
- No exact hidden formulas or reward spoilers in public news.
