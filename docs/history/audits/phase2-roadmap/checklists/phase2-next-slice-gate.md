# Phase 2 Next Slice Gate

Before starting the next runtime slice after `0.2.7`:

- `0.2.7` is merged or the next task is explicitly based on its branch.
- README, Roadmap, Deferred docs and AI context agree on current scope.
- Public site/news mismatch is either fixed or explicitly tracked.
- The chosen task has Goal / Scope / Non-goals / Acceptance Criteria / Tests / Manual QA / Release Surfaces.
- The task is not secretly combining party, market, equipment rebalance and achievements.
- Rewards/economy/loot changes are explicitly named and balance-reviewed.
- New player-facing Ukrainian copy follows Brand and avoids future-feature overpromising.
- Remort/reset behavior is specified for any new persistent state.
- Duplicate/stale callback behavior is specified for every mutation.
- A dev helper exists for timers/cooldowns if useful and safe.
