# Vision and Tone Alignment

## Still aligned

Квестарня still matches its core promise:

- Ukrainian-first, not localization;
- short Telegram actions instead of heavy UI;
- silly fantasy with readable systems;
- social actions through consent, not pressure;
- no pay-to-win;
- fun-per-message over spreadsheet-first design.

Recent `0.2.x` releases are more implementation-heavy than public-copy-heavy, but they serve the same direction:

- safe gifting tests opt-in social state;
- multi-enemy and threat escalation make PvE less flat;
- item tags and bandages make manatky more real;
- Bard Performance tests non-combat class identity near other players;
- Passage Search adds a tiny optional moment in Nyz;
- Player Abilities finally makes race/class visible as buttons.

## Main drift

The drift is **public perception**, not design intent:

- site/news look stale;
- Telegram bot description can overpromise guilds;
- some docs still point to Race Abilities as future after that PR is already active;
- Product Brief has an older support wording that should be synchronized with Brand.

## Tone risks

1. Too many releases can read as hidden state hardening rather than jokes and adventures.
2. Site/news lag can make the project feel smaller than it is.
3. Going directly to equipment/party systems may bury the korchma fantasy under architecture.

## Tone recovery plan

- Ship one visible identity/meta feature: achievements/title records.
- Ship one visible korchma-life feature: Daily Korchma Rounds.
- Refresh public site/news so the outside window sounds like current Kvestarnia.
- Add monster signature move copy after abilities so combat reads like authored absurd fantasy, not just button math.
