# Rebalanced Phase 2 Roadmap After Player Abilities MVP

## Principle

Phase 2 should stay **Social Combat & Interactions**, not become «big raid first» again. The next slices should improve visible player identity, daily return reasons and combat readability before risky economy/party systems.

## Proposed order

### Public Surface + Roadmap Sync

Type: docs / site / presentation cleanup.

Goal: make public site, news, Telegram description, README and roadmap match the actual `0.2.x` game after `0.2.7`.

Do before new runtime gameplay if possible.

### `0.2.8` — Achievements + Cosmetic Title Records

Goal: rewardless meta identity layer.

Non-negotiables:

- no XP/gold/items/stat bonuses;
- idempotent unlocks;
- hidden criteria stay hidden;
- disabled definitions allowed for unshipped systems;
- active title selection can be deferred.

### `0.2.9` — Daily Korchma Rounds

Goal: one short daily route through the korchma, completing two of three incidents and returning to Quest Table for a tiny reward.

Why now:

- strengthens korchma as living hub;
- supports retention without FOMO or combat pressure;
- creates future achievement events;
- reuses existing ledgers instead of a big new quest engine.

### `0.2.10` — Combat Balance + Monster Signature Moves Proof

Goal: after player abilities, verify balance and make several ordinary monsters feel more authored.

Scope:

- simulation/report update for class/race ability usage;
- tune obvious outliers only;
- 5–8 monster signature moves/flavor hooks;
- no reward/economy changes.

### `0.2.11` — Inventory / Equipment Clarity Pass

Goal: make manatky easier to inspect and compare before full equipment rework.

Scope:

- inventory filters;
- equipment comparison copy;
- visible item effect/value audit;
- no broad slot migration unless explicitly expanded.

### `0.2.12` — Postal Mantok Delivery

Goal: send one eligible manatka to a known recipient without same-location presence, preserving opt-in and privacy.

Scope guard:

- delivery fee as gold sink;
- no gold transfer;
- no market;
- no location leak;
- same item reservation model as safe gifting.

### `0.2.13` — Party Session Foundation

Goal: restart-safe recruiting/session foundation behind dev/feature flag; no boss, no rewards.

### `0.2.14` — Party vs One Boss

Goal: first production party combat proof. One party, one boss-like enemy, compact actions, conservative settlement.

### Later

- Big Barrel Brother / real raids;
- item-for-item trade;
- Shynok resale/recycling;
- full equipment rework;
- collections / museum;
- alpha telemetry / feedback / allowlist;
- guilds, seasons, leaderboards.
