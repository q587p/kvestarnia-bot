# 0.2.10 — Combat Balance and Monster Signature Moves

## Goal

After Player Abilities MVP, run a focused combat balance pass and add a small authored monster signature-move proof so fights read less generic without opening a broad combat rewrite.

## Scope

- Extend combat simulation/reporting for class/race ability usage, AoE enemy hits, support fallback and two-enemy pressure.
- Identify obvious same-level/high-level outliers.
- Tune only narrow numeric constants needed to keep ordinary fights near MVP goals.
- Add signature move/flavor hooks for 5–8 existing ordinary monsters.
- Keep all monster behavior deterministic/testable and replay-safe.
- Ensure result/journal replay stores enough data to avoid rerolling move flavor.

## Non-goals

- No new rewards, loot, XP/gold formulas or economy changes.
- No new player ability catalog.
- No party/raid/PvP integration.
- No broad monster AI rewrite.
- No hidden exact formulas in player-facing copy.

## Acceptance criteria

- Simulator can report class/race ability use and win-rate bands after `0.2.7`.
- Tuned fights remain readable and not overlong.
- Signature moves do not mutate rewards or quest/Yeger progress.
- Stale callbacks and battle journals replay stored outcomes.
- Player-facing copy is short Ukrainian and follows monster tone.

## Focused tests

- simulator coverage for all active classes/races;
- monster signature deterministic selection;
- replay/journal rendering;
- no reward/progress mutation;
- two-enemy AoE and same-turn response regressions.

## Manual Telegram QA

1. Run ordinary fights across several classes/races.
2. Trigger two-enemy threat fights.
3. Verify signature move copy is understandable and compact.
4. Reopen battle journal and terminal cards.
5. Verify rewards are unchanged except explicitly documented balance fixes.
