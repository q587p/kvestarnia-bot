# 0.2.11 — Inventory and Equipment Clarity Pass

## Goal

Make manatky easier to browse, compare and understand before attempting the full equipment slot rebalance.

## Scope

- Add inventory filters or views:
  - all;
  - equipment;
  - consumable/one-use;
  - story/priceless/memory if useful.
- Improve item detail with clearer effect/value/trade/use/equip state.
- Improve equipment comparison copy: current item vs candidate item, slot, replacement consequence.
- Audit current reachable manatky for obvious value/effect/rarity mismatches and document exceptions.
- Keep existing slot model unless a tiny safe helper extraction is required.

## Non-goals

- No full multi-slot equipment migration.
- No two-handed/offhand model.
- No market, crafting, auction or item-for-item trade.
- No combat item action catalog beyond existing one-use behavior.
- No random item stat generation.

## Acceptance criteria

- Large bags are easier to scan.
- Equipped/protected/story/one-use states are clear before mutation.
- Item detail and equipment screens agree about supported effects.
- Existing Shynok sale, Mantok Chest, Munchkin barter, safe gifting and remort protections still hold.
- No existing character becomes unreadable.
