# Phase 2 Roadmap Audit — Квестарня

Date: 12026-07-07  
Scope: repository documentation, current task registry, public README/product/tone docs, Phase 2 docs, recent PR metadata, and the active `0.2.30 — Mantok Ability Grants Foundation` branch/task doc.

## Executive summary

The project is still moving in the intended direction: a Telegram-first, Ukrainian-first, humorous fantasy RPG where a living Korchma is the social hub and manatky become stories, not just numbers.

The main drift is not tonal; it is sequencing. After `0.2.23–0.2.30`, the project has spent a long stretch on manatky/equipment power depth. This is useful and supports the "character matters" pillar, but Phase 2 is supposed to be Social Combat & Interactions first. After the active Mantok Ability Grants work closes, the roadmap should deliberately pivot back toward social retention loops: table games clarity/rewards, turn-based duel tournament rewards, better quest overview, Rogue reputation consequences, and only then fuller raids/guild direction.

## Recommended next decision

1. Finish `0.2.30 — Mantok Ability Grants Foundation`.
2. Do **not** let stacked feature work share `0.2.30` numbering.
3. If manual QA/fixes are still needed for gear actions, use `0.2.31 — Mantok Ability Grants QA Hardening`.
4. If Item Upgrades / Charkokovalnia is already the next desired branch, renumber it to `0.2.32` after the hardening gate.
5. Then pivot to social:
   - `0.2.33 — Turn-Based Duel Tournaments Rewards MVP`;
   - `0.2.34 — Rogue Reputation and Location Risk`;
   - `0.2.35 — Quest Overview Route`;
   - `0.2.36 — Shynok Resale / Korchmar Recycling`.

The exact version numbers can shift if `0.2.31` hardening is unnecessary, but the ordering should remain: **finish the current Mantok foundation cleanly, then return to social loops**.
