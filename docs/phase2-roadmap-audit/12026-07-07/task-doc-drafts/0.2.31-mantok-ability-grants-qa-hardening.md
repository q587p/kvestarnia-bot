# 0.2.31 - Mantok Ability Grants QA Hardening

## Goal

Close the release-risk gap after `0.2.30 — Mantok Ability Grants Foundation` without adding new runtime scope.

## Scope

- Finish manual Telegram QA evidence for gear-action buttons in:
  - ordinary persistent PvE;
  - two-enemy fights;
  - Big Barrel Brother / party-boss rounds;
  - turn-based duels.
- Harden stale/missing-grant/no-mana/cooldown callback behavior.
- Verify active equipment swaps during an active turn do not refill HP/mana or grant extra turns.
- Verify first gear-action achievement notification appears once.
- Verify `/lore` opens `📖 Перекази` but is not added to the Telegram side menu.
- Update QA docs, changelog/news if needed, compact context and task registry.

## Non-goals

- No new manatky.
- No new gear actions.
- No bleed balance changes unless a blocker is found.
- No Charkokovalnia / item upgrade logic.
- No Prisma schema or migration.
- No tournament or table-games changes.

## Acceptance criteria

- All `0.2.30` manual QA proof points are either passed or explicitly documented as follow-up.
- Stale/forged gear callbacks are no-op/replay-safe across PvE, Big Barrel and turn-based duels.
- Active card/journal copy stays readable for gear actions and bleed.
- No duplicate achievement unlocks from repeated/stale gear callbacks.

## Focused tests

- Existing `mantokAbilityGrants`, fight, partyBoss and turnBasedDuel tests.
- Focused regression for any manual QA bug fixed in this slice.
- `npm run check`.
