# 04 — Old Promises / Open Gaps

## Mostly fulfilled

- Phase 1 loop: character -> quest/fight -> reward -> inventory/equipment -> progress.
- Persistent combat with replay-safe rewards.
- Lightweight presence.
- Safe gifting and postal delivery.
- First social combat: quick and turn-based duels.
- First party/raid route: Big Barrel Brother.
- First class noncombat surfaces: Bard, Priest, Rogue.
- Mantok item identity: slots, coverage, balance, sets, ability grants in progress.

## Still open from older plans

### 1. Turn-based duel tournaments

Originally "tournament cards / recognition" stayed deferred. Now that turn-based duels and social rewards exist, this should become a real reward-bearing Korchma loop.

### 2. Full quest overview

The backlog now explicitly tracks that `Квести` should become a compact quest overview/journal rather than a duplicate table opener. This is a UX debt, not a lore/content problem.

### 3. Hunt / Yeger expansion

Still missing:
- lure/ambush table;
- wilderness-like surface;
- journal/progress collection;
- reputation table;
- background auto-resolution.
Current Yeger work is intentionally a milestone quest and supply gate, not a broad hunt engine.

### 4. Mantok Chest pending cleanup / instance safety

The Mantok Chest backlog notes old pending runs can accumulate and that stack-based inventory lacks item-instance identity. This is acceptable for alpha but should be watched as item volume grows.

### 5. Trading and resale

Safe gifting and postal delivery shipped. Broader item-for-item trade, Shynok resale, Korchmar recycling and any market-like feature remain future. Market/auction should remain deferred.

### 6. Food / drink buffs

Shynok drinks exist. Food buffs and more gold sinks remain open. These fit the Korchma fantasy, but should be capped and one-active-buff style.

### 7. Achievements / collections

Rewardless achievements exist, but collection systems remain open:
- Bestiary collection;
- Mantok museum;
- internal aggregate achievement analytics;
- social/remort achievement boards.

### 8. Fuller raids / party progression

Big Barrel Brother MVP exists, but Phase 4 goals remain open:
- weekly group goal;
- guild creation / guild XP;
- boss/guild boss;
- contribution-aware rare rewards.

### 9. Class/race/native combat action depth

`0.2.7` and `0.2.30` cover a lot, but native class/race identity still has room:
- class/race/combo action variants;
- active title abilities;
- epic-level abilities;
- shield/taunt later, not now.

## Things not lost but intentionally deferred

- market/auction;
- guild wars;
- Mini App/web client;
- paid power;
- forced item loss;
- broad party-vs-many runtime.
