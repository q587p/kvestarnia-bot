# Quest Flavor Routing

## Мета

Квести мають показувати, що раса, клас, звертання/path, титул і комбінація героя не лежать мертвими полями в базі.

Перший шар — не складна механіка, а інший спосіб взаємодії:

- персоналізований старт;
- альтернативна назва кнопки;
- додатковий outcome-line;
- маленький reward-note;
- інша already-completed/cooldown репліка;
- майбутній item inspection text.

Гумор/іронія/пародія мають бути важливіші за «правильний білд».

## Content contract для майбутніх квестів

Кожен новий квест має мати:

1. Neutral fallback, який працює для всіх.
2. Мінімум 2 race hooks.
3. Мінімум 2 class hooks.
4. Мінімум 1 combo hook.
5. Опційно 1 pronoun/path hook, але без серйозного лору й без прямого «для небінарних» у тексті.
6. Тести на fallback і принаймні один matching hook.

## Selector priority

Для одного placement-а:

1. combo hook;
2. class hook;
3. race hook;
4. path/pronoun hook;
5. fallback.

Для outcome можна дозволити 2 рядки:

- 1 combo/race/class line;
- 1 fallback/reward line.

Не більше, щоб не роздувати Telegram-message.

## Suggested TypeScript shape

```ts
export interface QuestFlavorHook {
  id: string;
  questId: string;
  placement: "start" | "choice" | "outcome" | "reward-note" | "already-completed" | "cooldown";
  selector: {
    raceIds?: string[];
    classIds?: string[];
    pronouns?: Pronoun[];
    paths?: CharacterPath[];
    combos?: Array<{ raceId: string; classId: string }>;
  };
  priority?: number;
  action?: string;
  label?: string;
  text: string;
}
```

For MVP, action labels can be text-only aliases over existing action ids. Do not create new reward keys for every class variant.

For authored methods shipped in `0.1.20`, the same idea is stricter: the player-facing button names the scene action even when race, class or signature influence selected the affordance/check/outcome. Avoid player-facing lines like `Расовий спосіб`, `Класова техніка`, `Точна race+class signature`, `Підпис методу` or raw signature formulas. If a result needs a title/name flourish, make it part of the sentence and keep grammar neutral.

Example:

```ts
{
  id: "quest.mimic-shawarma.choice.bureaucramancer.receipt",
  questId: "quest.mimic-shawarma",
  placement: "choice",
  action: "receipt",
  selector: { classIds: ["class.bureaucramancer"] },
  label: "📋 Вимагати форму на лаваш"
}
```

This still triggers the existing `receipt` action.

## Current quest: Підозріла шаурма

Base scene: на столі лежить шаурма, вона дихає, корчмар каже «то не моя».

Base actions:

- `poke` — тицьнути;
- `receipt` — попросити чек;
- `flee` — обережно відступити.

### Start hooks

#### Маг

> Соус на шаурмі світиться не за санітарними нормами. Ви майже впевнені: це або мімік, або дуже амбітний часник.

#### Бюрокромант

> На шаурмі немає печатки походження. Вона дихає ще до заповнення форми. Нахабство.

#### Вареник-мант

> Тісто всередині вас шепоче: «Це не наш формат, але теж родич по борошну».

#### Злодій

> Шаурма лежить так, ніби ховає гаманець. Або зуби. У будь-якому разі це виклик.

#### Бісини

> Шаурма дивиться на вас так, ніби теж хоче посперечатися про назву. Небезпечна вечеря.

#### Дрантогор

> На лаваші пляма, схожа на карту Остромагу. Або на соус. У вас уже були гірші маршрути.

#### Домовик

> Шаурма лежить на вашому столі. Якщо це пастка, вона принаймні має платити за оренду.

#### Русалка сухопутна

> Шаурма не мокра, але дивиться так, ніби знає море. Підозріло навіть для чайника.

#### Орк-інтелігент

> Перед вами харчовий обʼєкт із поведінковими відхиленнями. Час рецензії.

#### Мольфарська душа

> Ваш оберіг тихо просить не їсти те, що дихає краще за деяких знайомих.

### Choice label aliases

These labels should map to existing actions.

#### `receipt`

- Бюрокромант: `📋 Вимагати форму на лаваш`
- Орк-інтелігент: `📋 Провести етичну рецензію начинки`
- Бісини: `📋 Оскаржити назву в коментарях`
- Жрець: `📋 Благословити чек на правдивість`

#### `poke`

- Воїн: `🗡️ Тицьнути переконливо`
- Козак-характерник: `👁️ Подивитись так, щоб лаваш зніяковів`
- Вареник-мант: `🥟 Перевірити тістологічну родину`
- Дрантогор: `🗺️ Тицьнути в місце, де мав бути Остромаг`

#### `flee`

- Злодій: `🏃 Зникнути з рахунком гідності`
- Єгер: `🏃 Відійти по слідах соусу`
- Домовик: `🏃 Відступити за пічний суверенітет`
- Русалка сухопутна: `🏃 Відступити до найближчої калюжі`

### Outcome hooks

#### Маг + receipt

> Ви назвали три складні слова. Шаурма зрозуміла тільки «санітарна перевірка» й одразу стала менш містичною.

#### Бюрокромант + receipt

> Форма на лаваш виявилась довшою за сам лаваш. Мімік підписався зубами й юридично програв.

#### Вареник-мант + poke

> Тісто відчуло тісто. Шаурма образилась, що її назвали недовареним вареником.

#### Злодій + flee

> Ви відійшли так тихо, що шаурма ще хвилину шипіла на ваш силует за столом.

#### Домовик + poke

> Ви постукали по столу як власник території. Шаурма вперше задумалась про квартплату.

#### Бісини + receipt

> Суперечка про назву тривала 17 секунд. Шаурма не витримала й видала чек, аби тільки це скінчилось.

#### Дрантогор + poke

> Ви показали шаурмі маршрут з Остромагу. Вона заплуталась, видихнула соусом і втратила бойовий настрій.

#### Русалка сухопутна + flee

> Ви відійшли драматично, майже морською ходою. Уявний хвіст аплодував.

#### Орк-інтелігент + receipt

#### Мольфарська душа + poke

> Оберіг дзенькнув, туман кашлянув, шаурма вирішила, що вечеря сьогодні виїзна.

## Current fight probe: Сутичка з Міміком-шаурмою

Base actions:

- `attack`;
- `receipt`;
- `flee`.

Fight math must remain deterministic. Flavor can change text, not damage.

### Start hooks

- Воїн: «Мімік показав зуби. Ви показали план: дуже простий і металевий.»
- Маг: «Лаваш іскрить по краю. Це або магія, або стара проводка, але бити все одно доведеться.»
- Бард: «Шаурма розкрила зуби. У неї жахлива дикція, але агресивна сценічна присутність.»
- Злодій: «У міміка є спина. Десь. Треба лише творчо її знайти.»
- Жрець: «Це не вечеря, це спокуса з соусом. Суворий погляд уже заряджено.»
- Вареник-мант: «Тісто проти лаваша. Давнє протистояння, яке ніхто не просив.»
- Бюрокромант: «Сутичка без протоколу не рахується. Мімік про це ще не знає.»
- Єгер: «Сліди зубів ведуть прямо до зубів. Рідкісна, але зручна чесність.»
- Козак-характерник: «Мімік зубиться. Ви дивитесь. Туман робить вигляд, що просто проходив.»

### Outcome hooks

- Воїн + attack: «Ваш удар був настільки прямий, що навіть лаваш зрозумів сюжет.»
- Злодій + attack: «Ви знайшли міміку умовну спину. Мімік подав апеляцію до анатомії.»
- Бюрокромант + receipt: «Чек став зброєю масового оформлення. Мімік отримав шкоду по самоповазі.»
- Бард + flee: «Ви відступили в риму. Це не перемога, але дуже важко заперечити красиво.»
- Козак-характерник + attack: «Ви не стільки вдарили, скільки пояснили долю. Доля була з заліза.»
- Дрантогор + flee: «Ви відійшли до точки, де, за вашими словами, “точно був вхід в Остромаг”.»

## Already-completed / cooldown personalization

Додавати зрідка, не всюди.

### Шаурма already completed

- Бюрокромант: «Документи шаурми вже в архіві. Вона просила не відкривати справу до завтра.»
- Бісини: «Суперечку про назву шаурма вже програла. Сьогодні друга інстанція зачинена.»
- Вареник-мант: «Тістологічна перевірка завершена. Лаваш досі не вареник.»

### Льох cooldown

- Домовик: «Льох узяв паузу. Каже, треба провітрити вашу юрисдикцію.»

## Balance notes

Historical note: the first flavor-only PR did not change reward math. Runtime authored quest methods in `0.1.20` may use the bounded reward/cost ledger from `docs/QUEST_RESOLUTION_VARIETY.md`, but they still must not expose exact future rewards or hidden odds before commitment.

Перший PR не має міняти reward math. Якщо дуже хочеться мікро-винагороду:

- тільки `+1 XP` або `+1 gold`;
- тільки для альтернативного action label, який усе одно мапиться на base action;
- idempotency має лишатись через існуючий daily/cooldown key;
- тест на repeated callback обовʼязковий.

Краще спершу зробити текстову різноманітність. Вона безпечніша й краще служить restart-loop.
