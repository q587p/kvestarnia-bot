# Release Closeout and Handoff Prompt

Use this at the end of a versioned task before starting a new thread.

```text
Use $kvestarnia-release-checklist.

Close out the current versioned task.

Check:
- scope matches the task doc
- changed files are expected
- tests/checks are listed
- player-facing copy is Ukrainian
- release surfaces are correct if this is release-oriented
- risks/follow-ups are named

Output:
- release readiness
- tests/checks run
- manual QA
- changelog/news status
- remaining risks
- handoff summary for next fresh Codex thread
- recommended PR title

No tutorial.
```
